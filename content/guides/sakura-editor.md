# サクラエディタ 技術まとめ

## 基礎

Windows用の国産テキストエディタ。正規表現置換と矩形選択が便利。

### 主な用途

- ソース・SQLの整形
- Excelから貼り付けたデータの変換
- ログの調査（Grep）
- 文字コード・改行コードの確認

## コマンド

### 置換（Ctrl+R・正規表現にチェック）

```
^       →  --      行頭に付ける
$       →  ,       行末に付ける
^(.*)$  →  '$1',   囲んでカンマ
```

### 矩形選択

```
Alt+ドラッグ        矩形選択
Shift+Alt+矢印      キーボードで矩形選択
Shift+F6            矩形範囲選択開始
```

### よく使うショートカット

```
Ctrl+F  検索    Ctrl+R  置換
Ctrl+G  Grep    Ctrl+J  指定行へ
Ctrl+U  小文字  Ctrl+Shift+U  大文字
```

### 早見表：置換（正規表現）

| 操作 | コマンド・構文 |
| --- | --- |
| 行頭に付ける | `^  →  -- ` |
| 行末に付ける | `$  →  ,` |
| 囲んでカンマ（IN句） | `^(.*)$  →  '$1',` |
| タブ → カンマ | `\t  →  ,` |

### 早見表：矩形選択

| 操作 | コマンド・構文 |
| --- | --- |
| マウス | `Alt + ドラッグ` |
| キーボード | `Shift+Alt+矢印キー` |
| 選択開始 | `Shift+F6 → カーソル移動` |
| 列を削除 / コピー | `矩形選択 → Delete / Ctrl+C` |

### 早見表：検索・移動

| 操作 | コマンド・構文 |
| --- | --- |
| 検索 / 置換 | `Ctrl+F / Ctrl+R` |
| 次 / 前を検索 | `F3 / Shift+F3` |
| Grep（複数ファイル） | `Ctrl+G` |
| 指定行へジャンプ | `Ctrl+J` |

### 早見表：変換・編集

| 操作 | コマンド・構文 |
| --- | --- |
| 小文字 / 大文字 | `Ctrl+U / Ctrl+Shift+U` |
| 行のソート | `編集 → 高度な操作 → 昇順ソート` |
| 重複行の削除 | `編集 → 高度な操作 → uniq` |
| 文字コード指定で開き直す | `ファイル → 開き直す` |
