# WinMerge 技術まとめ

## 基礎

WinMerge は、Windows で使える無料（オープンソース）の差分比較・マージツールです。2つ（または3つ）の**ファイル**や**フォルダー**を並べて表示し、違う箇所を色付きで示します。差分を左右にコピーしてマージすることもできます。ソースコードのレビュー、設定ファイルの比較、リリース前の「本番と検証で何が違うか」の確認など、Windows 中心の現場では定番のツールです。

### できること

| 機能 | 内容 | 主な用途 |
| --- | --- | --- |
| ファイル比較（2方向） | 2つのテキストを左右に並べて差分を表示・編集 | ソース・設定ファイルの差分確認 |
| 3方向比較・マージ | 3つのファイルを左・中・右に並べる | 共通の元（ベース）と2つの変更版を見比べてマージ |
| フォルダー比較 | フォルダー内のファイルを一覧で比較（サブフォルダーも可） | リリース物件・バックアップとの差分確認 |
| 表形式の比較 | CSV / TSV を表として比較 | データファイルの確認 |
| バイナリ比較 | 16進表示で比較 | 実行ファイル・画像以外のバイナリ |
| 画像比較 | 画像の違う部分を強調表示 | 画面キャプチャの比較 |
| レポート出力 | 比較結果を HTML などで保存 | レビュー記録・エビデンス |
| プラグイン | 比較前にファイルを変換（展開）してから比較 | 対応する形式のテキスト化（Office 文書などは環境・プラグインに依存） |

### 差分の見方

- 差分のある行は背景色が付き、行の中の違う文字はさらに濃い色で示される
- 画面左端の**ロケーションペイン**に、ファイル全体のどこに差分があるかが表示される。クリックでその位置に移動できる
- 下部の**差分ペイン**で、選んだ行を上下に並べて文字単位で見比べられる

### フォルダー比較の比較方法

| 比較方法 | 判定のしかた | 特徴 |
| --- | --- | --- |
| 完全な内容（Full Contents） | ファイルの中身を比較。空白・改行の無視設定が効く | 正確だが遅い |
| 簡易な内容（Quick Contents） | 中身をバイト単位で比較 | 速い。無視設定は効かない |
| バイナリ内容 | バイト単位で比較 | バイナリファイル向け |
| 更新日時 / 更新日時とサイズ / サイズ | 中身は見ない | 非常に速いが、コピーで日時が変わると「違う」と判定される |

## 環境構築

### 1. インストール

- 公式サイトからインストーラー（64bit 版が基本）または ZIP のポータブル版をダウンロードする
- winget を使う場合は `winget install --id WinMerge.WinMerge -e`
- インストーラーで「エクスプローラーのコンテキストメニューに追加」を選んでおくと、右クリックから比較できる
- 表示言語は「表示 → 言語」で日本語に切り替えられる

既定のインストール先は `C:\Program Files\WinMerge\` で、実行ファイルは `WinMergeU.exe` です。コマンドラインから使う場合は、このフォルダーを環境変数 `PATH` に追加しておくと便利です。

### 2. 最初にしておく設定（編集 → 設定）

| 項目 | 場所 | おすすめ |
| --- | --- | --- |
| 空白の扱い | 比較 → 全般 → 空白 | 用途に合わせて「比較する / 変更を無視 / すべて無視」を選ぶ |
| 改行コードの違いを無視 | 比較 → 全般 | CRLF / LF の違いだけで全行が差分になるのを防ぐ |
| 大文字と小文字を区別しない | 比較 → 全般 | SQL など大文字小文字を区別しない言語で便利 |
| 移動ブロックの検出 | 比較 → 全般 | 行の並び替えを「削除＋追加」ではなく移動として表示 |
| 既定のコードページ | コードページ | 日本語環境なら Shift_JIS（932）か UTF-8 を、扱うファイルに合わせて選ぶ |
| タブ幅・行番号表示 | エディター | 行番号はレビュー時に必須 |

### 3. 動作確認

```bat
"C:\Program Files\WinMerge\WinMergeU.exe" C:\work\old\app.config C:\work\new\app.config
```

左右にファイルが表示され、差分の行に色が付けば準備完了です。

## コマンド

### 早見表：起動

| 操作 | コマンド・構文 |
| --- | --- |
| ファイル比較 | `WinMergeU.exe a.txt b.txt` |
| フォルダー比較 | `WinMergeU.exe C:\old C:\new` |
| サブフォルダーも含めて比較 | `WinMergeU.exe /r C:\old C:\new` |
| 3方向比較 | `WinMergeU.exe left.txt middle.txt right.txt` |
| 片側を読み取り専用 | `WinMergeU.exe /wl old.txt new.txt` |
| 見出しを付ける | `WinMergeU.exe /dl "本番" /dr "検証" prod.conf stg.conf` |
| 拡張子で絞り込み | `WinMergeU.exe /r /f "*.java;*.xml" C:\old C:\new` |
| レポート出力 | `WinMergeU.exe /r old new /minimize /noninteractive /or report.html` |

### 主なコマンドラインオプション

オプションは `/` と `-` のどちらでも指定できます。

| オプション | 意味 |
| --- | --- |
| `/r` | フォルダー比較でサブフォルダーも再帰的に比較する |
| `/f フィルター` | フィルター名、または `*.cpp;*.h` のようなファイルマスクを指定する |
| `/e` | `Esc` キーで WinMerge を閉じられるようにする |
| `/x` | 比較対象が同一なら、メッセージを出さずに閉じる |
| `/s` | 既に起動している WinMerge のウィンドウで開く（多重起動しない） |
| `/u` | 最近使ったファイルの一覧に追加しない |
| `/wl` / `/wm` / `/wr` | 左 / 中央 / 右を読み取り専用で開く |
| `/dl` / `/dm` / `/dr` | 左 / 中央 / 右のペインに表示する説明（見出し） |
| `/o 出力パス` | マージ結果の保存先 |
| `/or レポートパス` | 比較レポートを出力する |
| `/minimize` / `/maximize` | ウィンドウを最小化 / 最大化して起動 |
| `/noninteractive` | レポート出力などの処理が終わったら終了する |
| `/cp コードページ` | 文字コードを指定する（例: `/cp 932`、`/cp 65001`） |
| `/ignorews` / `/ignoreblanklines` / `/ignorecase` / `/ignoreeol` | 空白 / 空行 / 大文字小文字 / 改行コードの違いを無視する |

### 早見表：差分移動

| 操作 | キー |
| --- | --- |
| 次の差分 | `Alt+↓` |
| 前の差分 | `Alt+↑` |
| 最初 / 最後の差分 | `Alt+Home` / `Alt+End` |
| 再比較 | `F5` |
| 検索 | `Ctrl+F` |
| 行へ移動 | `Ctrl+G` |

### 早見表：マージ

| 操作 | キー・メニュー |
| --- | --- |
| 右へコピー | `Alt+→` |
| 左へコピー | `Alt+←` |
| すべて右へ / 左へ | マージ → すべて右へコピー / すべて左へコピー |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y` |
| 保存 | `Ctrl+S` |

### 早見表：設定

| 操作 | 場所 |
| --- | --- |
| 空白を無視 | 編集 → 設定 → 比較 → 空白: 無視 |
| 大文字小文字無視 | 比較 → 大文字と小文字を区別しない |
| 改行コード無視 | 比較 → 改行コードの違いを無視 |
| フィルター | ツール → フィルター（`*.class` などを除外） |

## サンプル

### フォルダー比較用のファイルフィルター（.flt）

ビルド成果物やバージョン管理のフォルダーを比較から外すフィルターです。「ツール → フィルター → ファイルフィルター → 新規作成」で作成し、次のように書きます。

```text
## リリース比較用フィルター
name: Release Compare
desc: ビルド成果物とVCSフォルダーを除外する

def: include

## 除外するファイル（正規表現）
f: \.class$
f: \.pdb$
f: \.log$
f: Thumbs\.db$

## 除外するフォルダー（正規表現）
d: \\\.git$
d: \\\.svn$
d: \\node_modules$
d: \\bin$
d: \\obj$
```

`def: include` は「基本はすべて比較し、`f:` `d:` に一致したものを除外する」という意味です。`def: exclude` にすると逆に「一致したものだけを比較」になります。フォルダーのパターンは `\\` で始まる正規表現で書きます。

### 行フィルターで「見なくてよい差分」を無視する

ツール → フィルター → 行フィルターに正規表現を登録すると、一致する行の差分を無視（色を薄く表示）できます。

| 目的 | 正規表現の例 |
| --- | --- |
| `//` コメント行を無視 | `^\s*//` |
| SQL のコメント行を無視 | `^\s*--` |
| 日時が入るヘッダー行を無視 | `^# Generated at ` |
| バージョン番号の行を無視 | `^\s*Version\s*=` |

### Git の差分表示に WinMerge を使う

Git には WinMerge 用の設定が組み込まれているため、ツール名を指定するだけで使えます（`WinMergeU.exe` が既定の場所にあるか `PATH` が通っている場合）。

```sh
git difftool --tool=winmerge HEAD~1 -- src/app.js
git config --global diff.tool winmerge
git config --global merge.tool winmerge
git difftool --dir-diff main feature/login     # ブランチ間をフォルダー比較で確認
```

起動オプションを自分で決めたい場合は、`.gitconfig` に直接書きます。

```ini
[diff]
    tool = winmerge
[difftool "winmerge"]
    cmd = \"C:/Program Files/WinMerge/WinMergeU.exe\" -e -u -wl -dl \"Before\" -dr \"After\" \"$LOCAL\" \"$REMOTE\"
[difftool]
    prompt = false
```

### 3方向マージ（ベース・自分・相手）

元のファイル（ベース）から2人が別々に修正した場合は、3方向比較を使います。中央にベースを置くと、左右それぞれの変更点がはっきりします。

```bat
WinMergeU.exe /wl /wr /dl "自分の修正" /dm "元のファイル" /dr "相手の修正" mine.txt base.txt theirs.txt /o merged.txt
```

左右を読み取り専用にして、左右のペインから必要な差分を中央（ベース）へコピーして取り込み、`/o` で指定したファイルに保存します。GUI では「ファイル → 開く」で3つ目のパスを指定すると3方向比較になります。

### リリース前の差分レポートを自動で作る

```bat
@echo off
set WM="C:\Program Files\WinMerge\WinMergeU.exe"
set OUT=C:\release\diff_report_%DATE:/=%.html

%WM% /r /f "Release Compare" /minimize /noninteractive /u ^
     /dl "前回リリース" /dr "今回リリース" ^
     /or %OUT% C:\release\v1.4.0 C:\release\v1.5.0

echo レポートを出力しました: %OUT%
```

出力した HTML をレビュー記録やリリース判定のエビデンスとして保存しておくと、「何を変えたか」を後から説明できます。

## エラー対応

| 症状・メッセージ | 主な原因 | 対処 |
| --- | --- | --- |
| `The selected files are identical.`（日本語表示では同一である旨のメッセージ） | 中身が同じ。または無視設定（空白・改行・大文字小文字）で差分がすべて消えた | 本当に同じか不安なら、無視設定をオフにして再比較する |
| 日本語が文字化けする | 文字コードの自動判定が外れた（Shift_JIS と UTF-8 の混在など） | ファイル → コードページで正しい文字コードを指定して開き直す。コマンドラインなら `/cp 932` |
| 全行が差分になる | 改行コード（CRLF / LF）や文字コードが違う、インデントのタブ / 空白の違い | 「改行コードの違いを無視」「空白を無視」を設定する。ステータスバーで改行コードと文字コードを確認する |
| フォルダー比較で中身が同じなのに「異なる」になる | 比較方法が「更新日時」になっている | 比較方法を「完全な内容」に変えて再比較する |
| フォルダー比較が非常に遅い | `node_modules` や `.git` など大量のファイルを含む | ファイルフィルターで除外する。まず「簡易な内容」で比較する |
| テキストなのにバイナリとして扱われる | ファイル内に NUL 文字が含まれる、UTF-16 の判定失敗 | コードページを指定して開き直す。ログなどに制御文字が混ざっていないか確認する |
| 保存できない | 読み取り専用で開いている（`/wl` など）、ファイルの属性・権限 | 読み取り専用を解除するか、別名で保存する |
| 比較中に「ファイルが外部で変更された」旨の確認が出る | 比較中に別のエディターやビルドがファイルを更新した | 再読み込みする。編集中の内容があれば先に別名で保存する |
| Office ファイル（Excel など）の中身が比較できない | 標準ではバイナリとして比較される | プラグインの自動展開を有効にする。Office のインストールが必要なプラグインもあるため、環境に合わせて確認する |

**「差分が多すぎて見られない」ときの切り分け順**

1. ステータスバーで、左右の**文字コード**と**改行コード**が同じか確認する
2. 「改行コードの違いを無視」「空白を無視」をオンにして再比較する
3. それでも多い場合は、整形ツール（フォーマッター）の有無や、自動生成ファイルではないかを確認する
4. 意味のない差分（日時・連番など）は行フィルターで無視する

## 実務Tips

### レビュー・リリース確認

- 本番と検証の設定ファイルは `/dl "本番" /dr "検証"` のように**見出しを付けて**比較する。左右の取り違えを防げる
- 誤って編集しないよう、参照するだけの側は `/wl` `/wr` で読み取り専用にする
- 無視設定（空白・改行・大文字小文字）をオンにしたまま比較すると、**本当は意味のある差分を見落とす**ことがある。最終確認はすべてオフで行う
- フォルダー比較では「左のみ」「右のみ」のファイルを必ず確認する。追加漏れ・削除漏れはここで見つかる

### 効率化

- エクスプローラーで2つのファイルを選んで右クリック → WinMerge で、すぐに比較できる
- 比較設定やフィルターはプロジェクトごとに作り分け、名前で `/f` から呼び出す
- 定型の比較（前回リリースとの比較など）はバッチにして、レポート出力まで自動化する
- WinSCP の「ディレクトリの比較」で差分のあるファイルを見つけ、ダウンロードしてから WinMerge で中身を比較する、という組み合わせがよく使われる

### 注意点

- WinMerge で編集して保存すると、元ファイルが直接書き換わる。マージ作業の前にバックアップを取るか、`/o` で別ファイルに出力する
- 文字コードを変えて保存すると、アプリが読めなくなることがある。保存時の文字コード・改行コードは元ファイルに合わせる
- 機密情報を含むファイルの比較レポート（HTML）は、共有フォルダーに置きっぱなしにしない
- バージョン管理されたファイルの差分確認は、まず `git diff` や Git の差分ツールとして WinMerge を使う。フォルダーごとコピーして比較すると、どれが最新か分からなくなりやすい
