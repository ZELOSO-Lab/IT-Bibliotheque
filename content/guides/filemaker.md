# FileMaker 技術まとめ

## 基礎

Claris FileMaker。ノーコード寄りの業務アプリ開発プラットフォーム。

### 主な用途

- 業務アプリの内製
- 顧客・案件管理
- iPad業務アプリ
- 小規模チームのデータベース

## コマンド

### 計算式: 条件分岐

```
If ( 売上 >= 10000 ; "A" ; "B" )
```

### 計算式: 文字列結合

```
姓 & " " & 名
```

### スクリプト: 検索

```
レコードを検索 [ 検索条件を指定 ; 状態: "有効" ]
```

### 早見表：計算式

| 操作 | コマンド・構文 |
| --- | --- |
| 条件分岐 | `If ( 売上 >= 10000 ; "A" ; "B" )` |
| 多分岐 | `Case ( 区分 = 1 ; "個人" ; 区分 = 2 ; "法人" ; "その他" )` |
| 文字列結合 | `姓 & " " & 名` |
| 変数 | `Let ( [ 税 = 0.1 ] ; 金額 * ( 1 + 税 ) )` |

### 早見表：テキスト・日付

| 操作 | コマンド・構文 |
| --- | --- |
| 部分抽出 | `Left ( テキスト ; 3 )  Middle ( テキスト ; 2 ; 3 )` |
| 置換 | `Substitute ( テキスト ; "-" ; "" )` |
| 今日 | `Get ( 日付 )` |
| 日付作成 | `Date ( 月 ; 日 ; 年 )` |

### 早見表：スクリプト

| 操作 | コマンド・構文 |
| --- | --- |
| 検索 | `レコードを検索 [ 記憶する ]` |
| レイアウト移動 | `レイアウト切り替え [ "一覧" ]` |
| 変数設定 | `変数を設定 [ $count ; 値: Get ( 対象レコード数 ) ]` |
| ループ | `ループ   …   レコード/検索条件/ページへ移動 [ 次の ; 最後まできたら終了 ] ループ終了` |

### 早見表：リレーション・関数

| 操作 | コマンド・構文 |
| --- | --- |
| 集計 | `Sum ( 明細::金額 )` |
| 件数 | `Count ( 明細::ID )` |
| 関連リスト | `List ( 明細::品名 )` |
| SQL 実行 | `ExecuteSQL ( "SELECT COUNT(*) FROM 顧客" ; "" ; "" )` |
