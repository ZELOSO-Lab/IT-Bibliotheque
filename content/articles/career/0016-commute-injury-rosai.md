# 【労務】通勤中に転倒して病院へ。労災（通勤災害）でやるべきこと。窓口で保険証を出さない、様式16号の3、休業は4日目から

> **最終確認日: 2026年10月28日**（労働者災害補償保険法・同施行規則、厚生労働省・各労働局の公表資料で確認）。一般的な手続きの解説です。自分のケースが通勤災害に当たるか、給付額がいくらになるかは、所轄の労働基準監督署が判断します。

## 現場の声

雨の朝、駅の階段で足を滑らせて、右手をついて転びました。最初は「ひねっただけ」と思って出社したものの、昼には手首が腫れてキーボードが打てない。

客先のリーダーに「病院に行ってきます」と伝えて近くの整形外科へ。受付で保険証を出しかけたところで、ふと「これ、通勤中のけがだけど、健康保険でいいんだっけ？」。

結論から言うと、**通勤中のけがに健康保険は使えません**。労災保険（通勤災害）で受診します。後から切り替えるのは手間がかかるので、**最初の受付**が一番大事です。

## 結論：やることは5つ

| 順番 | やること | いつ |
| --- | --- | --- |
| 1 | 病院の受付で「**通勤中のけがです。労災でお願いします**」と伝え、保険証は出さない | 受診時 |
| 2 | **会社（自社）に報告**する。SES・常駐なら自社の営業・総務にも | 当日中 |
| 3 | 転んだ場所・時刻・経路・状況を**メモと写真で記録**する | 当日中 |
| 4 | 請求書（**様式第16号の3**）を会社に証明してもらい、**病院に提出**する | 数日以内 |
| 5 | 仕事を休む場合は、**様式第16号の6**で休業給付を請求する（4日目から支給） | 休業後 |

- 通勤災害の治療費は、労災指定の病院なら**窓口負担なし**です
- 休業した場合、**4日目から**給付基礎日額の**60%＋特別支給金20%**が出ます
- 通勤災害では、初回の休業給付から**一部負担金200円**が差し引かれます

## 前提：「通勤災害」になる条件

労災保険の「通勤」は、**就業のために、住居と職場の間を、合理的な経路と方法で移動すること**です（労働者災害補償保険法 第7条第2項）。

| ケース | 通勤災害になる？ |
| --- | --- |
| 自宅から駅、駅の階段、電車内、駅から職場までの間で転倒 | **なる** |
| 電車が止まって、当日の交通事情で迂回した経路で転倒 | **なる**（迂回も合理的な経路） |
| 会社に届けた経路と違うが、普段使う別の合理的な経路で転倒 | なり得る（届出経路に限らない） |
| 帰りに映画を観に寄り道し、その後の帰り道で転倒 | **ならない**（逸脱・中断の後は通勤ではない） |
| 帰りに日用品を買うためにスーパーに寄り、店を出て経路に戻った後で転倒 | **なる**（日常生活上必要な行為。ただし店内にいる間は対象外） |
| 帰りに病院で診察を受け、経路に戻った後で転倒 | **なる**（同上） |

業務中のけが（客先のフロアで転倒など）は「通勤災害」ではなく「業務災害」で、使う様式が違います（様式第5号・第8号など）。

## 1. 病院の受付で伝えること

```text
通勤途中にけがをしました。労災（通勤災害）で受診したいです。
会社の書類は後日提出します。
```

- **健康保険証は出さない**でください。健康保険は、業務上や通勤中のけがには使えません
- **労災指定医療機関**なら、窓口での支払いなしで治療を受けられます。ただし書類が出るまで、一時的に預り金を求める病院もあります。書類を出せば精算されます
- 労災指定でない病院でいったん全額を払った場合は、後で**様式第16号の5**で費用を請求します（領収書は捨てない）
- 薬局にも「労災です」と伝えます。病院に出す請求書の**写し**を薬局に提出します

迷ったら、受診前に病院へ電話して「通勤災害で受診したい。労災指定か」を聞くと確実です。

## 2. 会社への報告

当日中に、**雇用主である自社**に報告します。SES・常駐で客先にいても、労災の手続きをするのは自社です。

```text
件名: 通勤中の負傷のご報告

△△です。本日8:20頃、通勤途中に○○駅の階段で転倒し、右手首を負傷しました。
□□整形外科を受診し、「右手首捻挫、全治2週間」の診断です。
通勤災害として労災保険での手続きをお願いしたく、必要書類をご教示ください。
本日の勤務は、客先には報告済みで、午後から復帰しています。
```

- 書類の様式は**厚生労働省のサイト**からダウンロードできます。会社の総務が用意してくれることも多いです
- 会社が「労災は使わないで」「健康保険で」と言っても、**労災の請求は労働者本人ができます**。事業主の証明をもらえない場合は、その事情を書いて労働基準監督署に相談してください

## 3. 当日のうちに記録しておくこと

後で「本当に通勤中だったのか」「どの経路か」を確認されることがあります。記憶は数日で曖昧になるので、**当日中**にメモします。

| 記録すること | 例 |
| --- | --- |
| 日時 | 2026年10月28日（水）8:20頃 |
| 場所 | ○○線××駅、東口の階段（上りの中ほど） |
| 経路 | 自宅 →（徒歩10分）→ ××駅 → ○○線 → △△駅 →（徒歩5分）→ 客先 |
| 状況 | 雨で階段が濡れていて足を滑らせ、右手をついた |
| 目撃者 | 駅員に声をかけた（いれば名前・連絡先） |
| 写真 | 転んだ場所、けがの部位、当日の運行情報（迂回した場合） |

**他人にぶつかられた、自転車にはねられた**など、相手がいる事故は「**第三者行為災害**」として、別に「第三者行為災害届」の提出が必要です。相手の名前・連絡先は必ず聞いてください。相手から賠償を受けた分は、労災の給付と調整されます。

## 4. 治療費の請求：様式第16号の3

| 受診した病院 | 使う様式 | 提出先 |
| --- | --- | --- |
| 労災指定医療機関 | **様式第16号の3**（療養給付たる療養の給付請求書） | 病院（病院経由で労基署へ） |
| 指定外の病院（全額立て替え） | **様式第16号の5**（療養給付たる療養の費用請求書） | 所轄の労働基準監督署 |
| 途中で病院を変える | 様式第16号の4（指定病院等の変更届） | 変更後の病院 |

様式第16号の3には、**事業主の証明欄**があります。会社に「災害の発生日時・場所・状況」が合っているか確認してもらい、証明をもらってから病院に出します。

通勤災害の用紙には、業務災害にはない**通勤経路の記入欄**があります。上の「記録」がそのまま使えます。

## 5. 休んだ場合：休業給付（様式第16号の6）

けがで働けず、賃金を受けない日があれば、**休業給付**を請求できます。

| 項目 | 内容 |
| --- | --- |
| 様式 | **様式第16号の6**（休業給付支給請求書）。医師の証明欄と事業主の証明欄がある |
| いつから | 休業の**4日目**から。最初の3日間は**待期期間**で、給付は出ない |
| 金額 | 給付基礎日額の**60%**（休業給付）＋**20%**（休業特別支給金）。合わせて約80% |
| 差し引かれるもの | 通勤災害は、初回の休業給付から**一部負担金200円** |
| 請求の単位 | 1か月ごとなど、休業期間を区切って請求するのが一般的 |

### 業務災害との違い：待期3日間は会社の補償がない

業務災害なら、最初の3日間は会社が平均賃金の60%以上を補償する義務があります（労働基準法 第76条）。**通勤災害にはこの義務がありません**。

最初の3日間は、**年次有給休暇を使う**と収入が途切れません。有給を使った日は賃金が出るので休業給付は出ませんが、待期期間は給付自体が出ない期間なので、損はしません。

給付基礎日額は、原則としてけがをした日の直前3か月の賃金総額を、その期間の暦日数で割った額（労働基準法の平均賃金）です。

## うっかり健康保険証を使ってしまったら

受診してしまっても、**労災に切り替えられます**。気づいた時点で病院に連絡してください。

| ケース | 手続き |
| --- | --- |
| 病院で切り替えてもらえる | 様式第16号の3を病院に提出。窓口で払った自己負担分は返金される |
| 病院で切り替えられない（月をまたいだ等） | 加入している健康保険（健保組合・協会けんぽ）に連絡し、**健康保険が払った分（7割など）を返納**。その領収書と、窓口で払った領収書を添えて、様式第16号の5で労基署に請求 |

後者は一時的に医療費の全額を立て替えることになり、手間もかかります。**最初の受付で「労災です」と言う**のが一番の近道です。

## よくある質問

| 質問 | 答え |
| --- | --- |
| 軽いけがでも労災を使うべき？ | 使ってください。後から悪化したときに、通勤災害として記録が残っていないと説明が難しくなる |
| 通勤災害を使うと会社に迷惑がかかる？ | 通勤災害は、業務災害と違って会社の労災保険料率（メリット制）に影響しない |
| 通勤災害でも解雇されない保護はある？ | 業務災害の療養中の解雇制限（労働基準法 第19条）は、**通勤災害には適用されない** |
| 請求に期限はある？ | 療養給付・休業給付は、**2年**で時効（労働者災害補償保険法 第42条）。休業給付は休業した日ごとに数える |
| 整骨院・接骨院でも使える？ | 使える場合があるが、手続きが別。事前に労基署か施術所に確認する |

## まとめ

- 通勤中のけがは**通勤災害**。**健康保険は使えない**。受付で「労災で」と伝える
- 書類は治療費が**様式第16号の3**（指定外は16号の5）、休業が**様式第16号の6**
- 休業給付は**4日目から**、給付基礎日額の**60%＋20%**。通勤災害は**待期3日間の会社補償がない**ので、有給を使う
- 当日中に**記録**と**自社への報告**。相手がいれば**第三者行為災害届**
- 治療中にもう1回けがをした場合は「[労災の治療中に2回目の労災。どうする？](/articles/second-rosai-during-treatment)」へ
