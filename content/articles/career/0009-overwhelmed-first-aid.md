# 【メンタル】高稼働で追い込まれた時に最初にやること。限界サインの見分け方、睡眠を取り戻す3日間、受診・相談の目安

> **最終確認日: 2026年10月21日**（労働安全衛生法・同規則、厚生労働省「こころの耳」、厚生労働省の相談窓口一覧で確認）。この記事は医療的な診断の代わりにはなりません。体調の判断は医師・専門家に相談してください。

## 現場の声

炎上気味の案件で、残業と休日出勤が続いていました。

- 目の前の席の人たちは楽しそうに話しているのに、自分が話しかけると「スンッ」と静かになる
- 自分が出られない会議で、遅延の理由を都合よく説明されているのではと不安になる
- 「契約を切られるかもしれない」と考えて夜中に目が覚める
- 寝不足で頭が回らず、簡単なミスが増える

気づいたら、周りの人の言動がすべて自分への悪意に見えていました。「人間不信になりかけている」と自覚した時点で、すでにかなり追い込まれていたのだと思います。

振り返ると、最初にやるべきだったのは**人間関係をどうにかすることではなく、眠ること**でした。

## 結論

追い込まれた時は、次の順番で対処します。

| 順番 | やること | 目的 |
| --- | --- | --- |
| 1 | **限界サインを確認する**（下のチェック表） | 「自力で立て直す段階」か「専門家に頼る段階」かを分ける |
| 2 | **今夜から3日間、睡眠を最優先にする** | 寝不足のままだと、判断も人の見方も悪い方に偏る |
| 3 | **業務量を1人で抱えず、上長に優先順位を決めてもらう** | 稼働そのものを下げる |
| 4 | **人間関係・将来の不安は、眠れてから考える** | 判断力が戻ってから取り組むほうが失敗しない |

人間関係や契約の不安への具体的な対処は、このシリーズの続きの記事で扱います。

## 1. 限界サインを確認する

次のうち、**2週間以上続いているもの**を数えます。

| 区分 | サイン |
| --- | --- |
| 睡眠 | 寝つけない、夜中や明け方に目が覚めて眠れない、休日に寝ても疲れが取れない |
| 気分 | 気分の落ち込みが続く、以前楽しめたことが楽しめない、理由もなく涙が出る |
| 思考 | 集中できない、簡単なミスが増える、決められない、悪い想像が止まらない |
| 体 | 食欲が落ちた（または増えた）、頭痛・胃痛・動悸、朝起き上がれない |
| 行動 | 出勤前に強い吐き気や腹痛がある、遅刻が増えた、飲酒量が増えた |

### 目安

- **すぐに相談する**: 「消えてしまいたい」「いなくなりたい」と考える。この場合は、仕事より先に下の相談窓口か医療機関に連絡してください
- **今週中に受診する**: 2週間以上続くサインが複数ある。特に「眠れない」と「気分の落ち込み」が両方ある
- **様子を見つつ立て直す**: サインはあるが2週間未満。下の「睡眠を取り戻す3日間」を試し、改善しなければ受診する

受診先は、**心療内科・精神科**か、普段のかかりつけ医です。「眠れない」「仕事のことで頭がいっぱいになる」と、症状をそのまま伝えれば十分です。予約が数週間先になることも多いので、迷ったら先に予約だけ取っておきます。

## 2. 今夜から3日間、睡眠を最優先にする

寝不足が続くと、相手の何気ない表情や言葉を**否定的に受け取りやすくなる**ことが知られています。「スンッとされた」「責められている」と感じる回数が増えたら、まず睡眠不足を疑います。

### 3日間でやること

| やること | 具体的には |
| --- | --- |
| **起きる時刻を固定する** | 寝る時刻ではなく起きる時刻を決める。休日も平日との差を2時間以内にする |
| **寝る1時間前に仕事を切る** | 社用チャット・メールの通知を切る。スマホは寝床に持ち込まない |
| **カフェインは14時まで** | コーヒー・エナジードリンクは午後の早い時間までにする |
| **寝酒をしない** | アルコールは寝つきを良くしても、夜中に目が覚めやすくなる |
| **昼休みに15〜20分だけ仮眠** | 15時より前に、短く。長く寝ると夜に眠れなくなる |
| **朝に日光を浴びる** | 通勤時に外の光を浴びる。体内時計が整い、夜に眠くなりやすい |
| **夜中に目が覚めて不安が止まらない時は、紙に書いて寝床を離れる** | 頭の中で考え続けず、「明日考えること」として書き出す。眠くなったら寝床に戻る |

3日間試しても眠れない、または寝ても疲れが取れない場合は、セルフケアの範囲を超えています。受診して医師に相談してください。睡眠薬などの判断は医師が行います。

## 3. 業務量を1人で抱えない

睡眠を削っている原因が稼働の高さなら、**稼働そのものを下げる相談**が必要です。「頑張れば何とかなる」量ではないから追い込まれています。

### 上長への相談の型

「できません」ではなく、**優先順位を決めてもらう**形で相談します。

```text
件名: 作業の優先順位のご相談

現在、以下の作業を並行して担当しています。
  1. ○○機能の改修（期限 10/25）残り工数 3人日
  2. △△の単体テスト（期限 10/28）残り工数 4人日
  3. □□の調査依頼（期限 未定）残り工数 2人日

10/28までの稼働可能時間は 約5人日のため、すべてを期限内に終えるには
休日出勤を含めても不足します。
どの作業を優先し、どの作業を後ろ倒し・分担するか、ご判断をいただけますか。
```

ポイントは3つです。

- **作業・期限・残り工数を並べる**。感情ではなく数字で、物理的に足りないことを示す
- **判断を上長に渡す**。優先順位を決めるのは管理する側の仕事です
- **SES・常駐の場合は、常駐先のリーダーと自社の上長（営業）の両方に共有する**。自社側が状況を知らないと、契約や稼働の調整ができません

自分の残業時間が法律の上限に近づいていないかは、「[36協定を結んでいたら何時間まで働ける？](/articles/saburoku-kyotei-overtime-limit)」で確認できます。

## 4. 長時間労働なら、産業医の面接指導を申し出る

時間外・休日労働が**月80時間を超え**、疲労がたまっている労働者が申し出た場合、会社は医師による面接指導を行う義務があります（労働安全衛生法第66条の8、労働安全衛生規則第52条の2・第52条の3）。

- 申し出先は**雇用している会社**です。SES・常駐の場合は、常駐先ではなく**自社**の人事・総務・上長に申し出ます
- 常時50人以上の労働者がいる事業場には、産業医の選任義務があります（労働安全衛生法第13条）。50人未満で産業医がいない場合は、地域産業保健センターを利用できる場合があります
- ストレスチェックは、現在は50人以上の事業場に実施義務があります（労働安全衛生法第66条の10）。2025年5月公布の改正法で、50人未満の事業場にも義務化されることが決まっています（施行は公布から3年以内）

月80時間に届かなくても、体調に不安があれば会社に相談してかまいません。

## まとめ

- 追い込まれた時に最初にやるのは、**限界サインの確認**と**睡眠の確保**
- 寝不足のままだと、人の言動を悪く受け取りやすくなる。**人間関係の判断は眠れてから**
- 業務量は「できません」ではなく、**作業・期限・工数を並べて優先順位を決めてもらう**
- 2週間以上続くサインが複数あれば**受診**。迷ったら外部の窓口に**匿名で相談**してよい
