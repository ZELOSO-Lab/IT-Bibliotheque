# 【働き方】駅に着いたら運転見合わせ。最初の5分でやること、遅刻・振替輸送・遅延証明の扱いと、次から慌てないための備え

> **最終確認日: 2026年10月28日**（労働者災害補償保険法、東京労働局・鉄道会社の公表資料で確認）。振替輸送や遅延証明書の扱いは鉄道会社ごとに違います。遅刻・交通費の扱いは自社の就業規則で決まります。

## 現場の声

朝8時すぎ、改札の前で足が止まりました。電光掲示板に「人身事故のため運転を見合わせています。再開見込みは9時30分頃」。

周りの人は一斉にスマホを見て、タクシー乗り場には行列。私も慌てて別の路線に向かい、乗り換えを2回間違え、結局は1時間半の遅刻。客先のリーダーには遅れると伝えたものの、**自社の営業には連絡を忘れていて**、後で「勤怠の連絡が来ていない」と言われました。

焦って動くほど、遅れも出費も増えます。止まった瞬間にやることは、**連絡・判断・記録**の3つだけです。

## 結論：最初の5分は「連絡 → 判断 → 記録」

| 順番 | やること | 目安 |
| --- | --- | --- |
| 1. 連絡 | 「遅れる可能性がある」と**先に**一報。SES・常駐なら**客先と自社の両方** | 1分 |
| 2. 判断 | 再開見込みを見て「待つ／迂回する／在宅・休みに切り替える」を決める | 3分 |
| 3. 記録 | 掲示板・運行情報のスクリーンショットを撮る。遅延証明書は後でWebで取れる | 1分 |

- **遅れが確定してから連絡するのでは遅い**です。「見合わせ中、到着時刻は改めて連絡します」で十分です
- 迂回は「早く着く」より「確実に着く」ルートを選びます
- 遅刻の給与の扱いは**就業規則次第**です。遅延証明書があれば控除しない会社が多いですが、法律で決まっているわけではありません

## 1. 連絡：遅れる「かもしれない」段階で一報を入れる

### 誰に連絡するか

| 働き方 | 連絡先 |
| --- | --- |
| 自社勤務 | 上司（チャットのルールがあればそれに従う） |
| SES・常駐 | **客先のリーダー**と**自社の営業（または勤怠担当）**の両方 |

SES・常駐では、勤怠を管理しているのは**雇用主である自社**です。客先にだけ連絡して、自社への連絡が漏れるのはよくある失敗です。

### そのまま使える連絡文

```text
おはようございます。△△です。
○○線が人身事故で運転見合わせ中のため、到着が遅れる見込みです。
現在××駅にいます。再開見込みは9:30頃とのことで、迂回ルートで向かいます。
到着時刻がわかり次第、改めて連絡します。
（遅延証明書は取得しておきます）
```

- 「現在地」「理由」「次にいつ連絡するか」の3つがあれば、受け取った側は予定を組み直せます
- 午前中に会議や作業開始の予定がある場合は、**代わりに対応できる人**や**オンライン参加できるか**も添えます

## 2. 判断：待つ・迂回する・切り替える

### 判断の目安

| 状況 | 選択肢 |
| --- | --- |
| 再開見込みが**30分以内**、または迂回が大回りになる | 駅で待つ（ホームではなく改札外などの安全な場所で） |
| 再開見込みが**30分以上**、または「見込み未定」 | 別路線・バスで迂回する |
| 迂回しても2時間以上かかる、在宅勤務が認められている | 上司に相談し、**在宅勤務や午前休**に切り替える |
| 台風・大雪などで全線が止まりそう | 無理に出勤しない。会社の判断を仰ぐ |

「人身事故」の場合、再開まで1時間前後かかることが珍しくありません。「見込み未定」の表示なら、迂回を前提に動いたほうが早く着けます。

### 振替輸送の注意点：ICカードのチャージ利用は対象外

振替輸送は、止まった路線の乗車券で、他社の路線に追加料金なしで乗れる制度です。ただし、**対象になる乗車券が決まっています**。首都圏の大手私鉄（東急電鉄）では、次のとおりです。

| 振替輸送の対象になる | 対象にならない |
| --- | --- |
| 定期券の区間内（Suica・PASMO定期券、磁気定期券） | ICカードの**チャージ残額**での利用 |
| きっぷ・回数券の区間内 | 有効期間切れの定期券、区間外の利用 |
| | クレジットカードのタッチ決済 |

- ICカードのチャージ残額で乗っている場合は、迂回先の運賃を**自分で払う**ことになります
- 振替輸送を使うには、**改札で振替乗車票を受け取る**などの手続きが必要な場合があります。駅の案内に従ってください
- 細かい扱いは鉄道会社ごとに違います。普段使う路線の「振替輸送のご案内」を一度読んでおくと安心です

### タクシー代は誰が払う？

**会社の規程次第**です。法律で会社に負担義務があるわけではありません。自己判断でタクシーに乗る前に、上司に一言確認してください。領収書は必ずもらいます。

## 3. 記録：遅延証明書とスクリーンショット

### 遅延証明書はWebで取れる

首都圏の多くの鉄道会社は、**Webサイトで遅延証明書を発行**しています。駅の窓口に並ぶ必要はありません。

- 発行されるのは一定時間（5分以上など）の遅れがあった時間帯・区間です。基準は鉄道会社ごとに違います
- 掲載期間が限られています（数日〜1か月程度など）。**当日中に保存**しておくと安心です
- 証明書は「その時間帯に列車が遅れた」ことの証明で、「あなたが乗っていた」証明ではありません

### スクリーンショットを撮っておく

駅の掲示板や運行情報アプリの画面を撮っておくと、遅延証明書が出ない区間（バスなど）や、上司への説明に使えます。

## 遅刻した時の給与と勤怠

| よくある疑問 | 考え方 |
| --- | --- |
| 電車の遅延で遅刻したら給料は引かれる？ | 働いていない時間の賃金は払わなくてよい（ノーワーク・ノーペイ）のが原則。ただし、**遅延証明書があれば控除しない**と決めている会社が多い。就業規則を確認 |
| 遅刻が評価に響く？ | 会社の運用次第。**事前に連絡して、証明書を出した**事実が大事 |
| 遅れた分、残業して取り戻すべき？ | 会社の指示に従う。自己判断で残ると勤怠上の扱いが曖昧になる |
| フレックスタイム制の場合は？ | コアタイムに遅れた場合の扱いを就業規則で確認する |

## 迂回中にけがをしたら：通勤災害になる

迂回中は普段と違う駅・道を急いで歩くので、転倒しやすくなります。

**当日の交通事情で迂回した経路も、通勤の「合理的な経路」に含まれます**（東京労働局の解説）。迂回ルートで転んでけがをした場合も、通勤災害として労災保険の対象になり得ます。

- 「合理的な理由がなく著しく遠回り」になる経路は対象外です
- 迂回の途中で通勤と関係のない寄り道（買い物以外の私用など）をすると、その間と、その後の移動は通勤になりません

けがをした時の手続きは「[通勤中に転倒して病院へ。労災（通勤災害）でやるべきこと](/articles/commute-injury-rosai)」にまとめています。運行情報のスクリーンショットは、迂回した理由の記録にもなります。

## 帰りに止まった場合

帰宅時に大規模に止まった場合（地震・台風など）は、**無理に歩いて帰らない**のが基本です。

- 東京都では条例で、事業者に従業員を**一斉に帰宅させない**よう努めること（一斉帰宅の抑制）と、**3日分の備蓄**が求められています
- 会社やビルの指示に従い、職場で待機するか、自治体の一時滞在施設を使います
- 家族との連絡手段（災害用伝言ダイヤル171など）を決めておきます

## 次から慌てないための備え

| 備え | 具体的に |
| --- | --- |
| 迂回ルートを**2本**決めておく | 別の鉄道路線1本＋バス1本など。所要時間と運賃も控えておく |
| 運行情報の通知を設定 | 鉄道会社の公式アプリや乗換アプリで、普段使う路線の運行情報をプッシュ通知にする |
| 連絡先と連絡文を保存 | 客先・自社の連絡先と、上の連絡文テンプレートをスマホのメモに入れておく |
| 振替輸送の対象を確認 | 定期券の区間を確認。区間外はIC残額払いになるので、残額に余裕を持たせる |
| 計画運休は前日に確認 | 台風・大雪の予報が出たら、前日夜に計画運休の発表を確認し、上司と出勤方法を相談 |
| 在宅勤務の条件を確認 | 交通障害で在宅に切り替えられるか、事前に確認しておく。PCを持ち帰れるかどうかも |
| 就業規則を一度読む | 遅延による遅刻の扱い、タクシー代の精算ルール、災害時の出勤ルール |

## まとめ

- 止まったら、**連絡 → 判断 → 記録**の順に5分で済ませる
- SES・常駐は、**客先と自社の両方**に連絡する
- 振替輸送は、**ICカードのチャージ利用は対象外**（定期券の区間内は対象）
- 遅刻の給与の扱いは**就業規則次第**。遅延証明書は当日中にWebで保存する
- 迂回した経路でのけがも、**通勤災害の対象になり得る**
