# 【学習】働きながら資格に合格するおすすめの勉強方法。忙しい現場でも続く「量のノルマ」と、AWS SAAの12週間計画例

> **最終確認日: 2026年10月19日**。試験の情報は各公式サイトで確認してください。

## 現場の声

応用情報技術者試験の参考書を買い、1ページ目から丁寧に読み始めました。「毎日1時間」と決めていましたが、3章あたりで結合テストが始まり、帰宅は毎日23時過ぎ。1時間がゼロになり、2週間後には何を読んだか覚えていませんでした。

合格した先輩のやり方は、まったく違いました。

- 参考書は**さっと1周**だけ。あとは**ひたすら過去問**
- ノルマは「1日1時間」ではなく「**1日10問**」
- 疲れた日は「**3問だけ**」でもいいから、**ゼロの日を作らない**

この記事では、働きながらでも続けられる勉強方法をまとめます。

## 結論：続けるための5つのルール

| ルール | 内容 |
| --- | --- |
| 1. 受験日を先に決める | 締切がないと延びる。申込・予約を先にする |
| 2. インプット3：アウトプット7 | 参考書は全体像をつかむ1周だけ。残りは問題演習 |
| 3. ノルマは「時間」ではなく「量」 | 「1日10問」。疲れた日の最低ラインは「3問」 |
| 4. 間違えた理由を1行で書く | 「なぜ他の選択肢はダメか」を説明できるまで復習 |
| 5. 模試の点数で受験を判断する | **3回連続で合格ライン＋10%**を超えたら仕上げ完了 |

## 1. 受験日を先に決める

勉強を始める前に、受験日を決めて申し込みます。申込の流れは「[資格を取得するには](https://itbibliotheque.wordpress.com/?name=how-to-get-it-certification)」を参照してください。

- 学習時間の目安 ÷ 1週間で確保できる時間 ＝ 必要な週数
- 繁忙期に止まる前提で、**予備を2週**入れる

## 2. インプット3：アウトプット7

参考書を完璧に読んでから問題を解く、という順番は時間がかかりすぎます。

1. **参考書（または動画講座）を1周**: 分からなくても止まらず、全体像と用語に慣れる
2. **過去問・問題集を解く**: 分野別に解き、間違えたところだけ参考書に戻る
3. **2周目・3周目**: 間違えた問題だけを解き直す

IPA試験は、公式サイトで**過去問題や公開問題**が公開されています。まずは公式の問題で出題の傾向をつかみましょう。

## 3. ノルマは「時間」ではなく「量」

「1日1時間」は、残業が続くとすぐに守れなくなります。守れない日が続くと、自己嫌悪でやめてしまいます。

| 日の状態 | ノルマ |
| --- | --- |
| 通常の日 | 10問 |
| 疲れた日 | **3問だけ**（ゼロにしない） |
| 休日 | 模試を通しで解く、ハンズオン |

- 通勤時間は、スマホで動画講座や問題アプリを使います。座れなくてもできることを平日に回します。
- **頭を使う学習**（模試、記述式、ハンズオン）は、休日のまとまった時間に回します。
- 睡眠を削る学習はしません。仕事のミスと学習効率の両方が落ちます。

## 4. 間違えた理由を1行で書く

問題を暗記しただけでは、本番の初見の問題で落ちます。間違えた問題には、理由を1行で残します。

```text
No.23  NG  正解: ウ
理由: 「可用性」を「完全性」と混同した。可用性＝使いたいときに使える、完全性＝改ざんされていない
```

- 選択肢ごとに「**なぜ正しいか・なぜダメか**」を説明できたら、その問題は卒業です。
- 1行メモは、**受験前日の見直し**にそのまま使えます。

## 5. 模試の点数で受験を判断する

「なんとなく不安」で受験日を延ばさないよう、点数で判断します。

- 合格ラインが60%の試験なら、**模試3回連続で70%以上**
- AWS SAA（合格ライン720/1000）なら、**模試3回連続で80%以上**

届かない場合は、正答率が低い分野だけに絞って**1週間追加**します。最初からやり直しはしません。

## 計画例：AWS Solutions Architect – Associate を12週間で

週10時間（合計約120時間）で、AWS SAA（SAA-C03）を受ける計画例です。

| フェーズ | 期間 | やること | 次に進む条件 |
| --- | --- | --- | --- |
| ① 全体像 | 1〜3週 | 動画講座で主要サービスを1周。用語に慣れる | 主要サービス（EC2・S3・VPC・RDS・IAMなど）を一言で説明できる |
| ② 理解＋手を動かす | 4〜7週 | 講座2周目。無料利用枠で EC2・S3・VPC・RDS を実際に触る | 分野別問題で正答率60%以上 |
| ③ 問題演習 | 8〜10週 | 模試・問題集を解き、間違えた理由を1行メモ | 模試70%以上 |
| ④ 仕上げ | 11〜12週 | 苦手分野をつぶし、模試を回す | **模試3回連続80%以上 → 受験** |

**1週間の型（合計 約10時間）**

| 時間帯 | 時間 | やること |
| --- | --- | --- |
| 平日の通勤（往復） | 40分×5日 | 動画講座を1.5倍速で視聴。後半は問題アプリ |
| 平日の帰宅後 | 20〜30分×5日 | 問題を5〜10問 |
| 休日 | 4時間 | ハンズオン、模試を通しで解く |

- AWSを実際に触るときは、アカウントを作った直後に**請求アラート**（例: 予算5ドル）を設定します。EC2・RDS・NAT Gateway は消し忘れると課金されるので、使い終わったらその日のうちに削除します。
- AWSの主要サービスとよく使うコマンドは、[AWSの技術まとめ](/technology/aws/guide/)にまとめています。

## リスクと対策

| リスク | 対策 |
| --- | --- |
| 繁忙期で学習が止まる | ノルマを「3問」まで下げる。2週止まったら受験日を2週後ろにずらす（最初からやり直さない） |
| 問題を暗記して合格した気になる | 選択肢ごとに理由を説明できるか確認する |
| 模試の点数が伸びない | 正答率が低い分野だけを1週間集中して解く |
| 不合格 | 結果レポートで弱い分野を確認し、そこだけ2〜3週やり直して再受験 |

## まとめ

- 働きながらの勉強は、**受験日を先に決めて、問題演習中心**で進める
- ノルマは「時間」ではなく「**問題数**」。疲れた日も**ゼロにしない**
- 模試が**3回連続で基準を超えたら受験**。届かなければ弱い分野だけ追加する
