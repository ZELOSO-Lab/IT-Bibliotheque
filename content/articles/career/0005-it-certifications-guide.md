# 【資格】エンジニアの資格はどれを取る？ 経験年数と現場の役割から選ぶIT資格マップ（国家資格・ベンダー資格）

> **最終確認日: 2026年10月19日**（IPA・各ベンダーの公式サイトで確認）。試験制度は変わることがあります。

## 現場の声

配属2年目の面談で、上司から言われました。

「来期の目標に、資格を1つ入れておいて」

調べると、国家試験だけで10以上、ベンダー資格を合わせると数え切れません。先輩に聞くと「基本情報は取っておけ」「いや、今はAWSだ」「現場で使うのはOracleだから」と、人によって答えが違います。

結局、大事なのは**今の現場で使う技術**と、**次に担当したい工程**から選ぶことでした。この記事では、迷ったときの選び方を整理します。

## 結論：迷ったらこの順番

| 経験 | まず取る | 次に取る |
| --- | --- | --- |
| IT未経験〜1年目 | ITパスポート（IP） | 基本情報技術者（FE） |
| 2〜4年目 | 基本情報技術者（FE） | 応用情報技術者（AP）＋現場で使う技術のベンダー資格 |
| 5年目〜 | 応用情報技術者（AP） | 担当したい分野の高度試験（DB・NW・SC・PMなど） |

- **国家試験**（IPA）は、技術の土台と「工程全体が分かる」ことの証明になります。会社の資格手当・昇格要件になっていることが多いです。
- **ベンダー資格**（AWS・Oracle・Linuxなど）は、特定の製品を**すぐ使える**ことの証明です。案件のアサインや単価に直結しやすいです。

## IPAの国家試験（情報処理技術者試験・情報処理安全確保支援士試験）

| 区分 | 略称 | レベル | 向いている人 |
| --- | --- | --- | --- |
| ITパスポート | IP | 1 | IT未経験、営業・事務職、新人 |
| 情報セキュリティマネジメント | SG | 2 | 情報システム部門、セキュリティ担当の入口 |
| 基本情報技術者 | FE | 2 | プログラマ、新人〜3年目のエンジニア |
| 応用情報技術者 | AP | 3 | 設計・リーダーを目指すエンジニア |
| データベーススペシャリスト | DB | 4 | DB設計・SQLチューニング担当 |
| ネットワークスペシャリスト | NW | 4 | ネットワーク設計・インフラ担当 |
| 情報処理安全確保支援士 | SC | 4 | セキュリティ担当（合格後に登録すると国家資格「登録セキスペ」） |
| プロジェクトマネージャ | PM | 4 | PM・PL |
| システムアーキテクト | SA | 4 | 上流工程（要件定義・基本設計） |
| ITストラテジスト | ST | 4 | IT戦略・企画 |
| ITサービスマネージャ | SM | 4 | 運用・保守の責任者 |
| エンベデッドシステムスペシャリスト | ES | 4 | 組込み系 |
| システム監査技術者 | AU | 4 | 監査・内部統制 |

### 2026年度〜2027年度の大きな変更

- **応用情報と高度試験・支援士は、2026年度からCBT方式**（会場のパソコンで受験）になり、春期・秋期から**前期・後期**に変わりました。
- **IP・SG・FEは、2026年12月27日で一時休止**します（会場によってはそれより前に終了）。再開時期はIPAが告知する予定です。
- IPAは**2027年度から新しい試験制度へ移行する予定**です。2026年3月公表の見直し案（検討中の内容）では、応用情報と高度試験を再編した「プロフェッショナルデジタルスキル試験（仮称）」と、「データマネジメント試験（仮称）」の新設が示されています。

これから受ける人は、**受験前に必ずIPAの公式サイトで最新の日程を確認**してください。取り方は「[資格を取得するには](https://itbibliotheque.wordpress.com/?name=how-to-get-it-certification)」で解説します。

## ベンダー資格：現場で使う技術から選ぶ

| 分野 | 資格 | 現場で効く場面 |
| --- | --- | --- |
| クラウド | AWS Certified Cloud Practitioner → **Solutions Architect – Associate（SAA）** | AWS案件のアサイン。設計レビューで「なぜこの構成か」を説明できる |
| データベース | ORACLE MASTER（Bronze → Silver → Gold） | Oracleを使う業務システムの開発・保守。SQLやバックアップの話が通じる |
| Linux | LinuC / LPIC（レベル1 → 2） | サーバー作業、ログ調査、シェルスクリプト |
| Java | Oracle認定 Javaプログラマ（Silver → Gold） | Java案件の新規参画。言語仕様の細かい挙動を押さえられる |
| ネットワーク | CCNA | インフラ・ネットワーク構築の入口 |

- ベンダー資格には**有効期限や再認定**があるものがあります（例: AWS認定は3年）。
- AWSの学習の進め方は「[おすすめの勉強方法](https://itbibliotheque.wordpress.com/?name=study-methods)」で、12週間の計画例を紹介しています。技術の概要は[AWSの技術まとめ](/technology/aws/guide/)も参照してください。

## 工程別のおすすめ

| 担当している・担当したい工程 | おすすめ |
| --- | --- |
| 製造・単体テスト（PG） | FE、現場の言語のベンダー資格（Java Silver など） |
| 詳細設計・結合テスト（SE） | AP、DB（DBを触る業務システムなら） |
| 要件定義・基本設計（上流） | AP → SA |
| 運用・保守 | LinuC / LPIC、SM、AWS SAA |
| PL・PM | AP → PM |
| セキュリティ | SG → SC |

## 資格を選ぶときの注意

- **資格手当・報奨金の対象**を先に確認しましょう。会社によって対象資格と金額が大きく違います。
- 資格は**実務経験の代わりにはなりません**。資格で得た知識を、今の現場の作業（設計書のレビュー、障害調査など）で使ってはじめて評価につながります。
- 受験料は1回数千円〜数万円です。会社の**受験料補助**が使えることもあります。

## まとめ

- 迷ったら、**IP → FE → AP → 高度試験**の順番に、**現場で使う技術のベンダー資格**を組み合わせる
- 国家試験は土台と工程全体の理解、ベンダー資格は製品をすぐ使えることの証明
- IPA試験は**2026年12月の一時休止**と**2027年度の制度見直し**があるため、日程は必ず公式で確認する
