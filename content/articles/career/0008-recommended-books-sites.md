# 【学習】資格・実務に役立つおすすめの本とサイト。現場のエンジニアが実際に使っている定番をレベル別に紹介

> **最終確認日: 2026年10月19日**。書籍は毎年改訂されるものが多いので、**受験する年度・試験バージョンに対応した版**を選んでください。

## 現場の声

基本情報技術者試験の勉強を始めようと書店に行くと、同じ試験の参考書が10冊以上並んでいました。とりあえず一番分厚い本を買いましたが、文字ばかりで3日で挫折しました。

先輩に聞くと、こう言われました。

- 「最初の1冊は**図が多くて薄い本**。分厚い本は辞書として使う」
- 「本は1冊でいい。あとは**過去問サイト**で問題を解く」
- 「資格が終わったら、**現場で長く使える本**を読むといい」

この記事では、目的別に定番の本とサイトを紹介します。

## 結論：教材は「入門書1冊＋問題演習1つ＋公式」に絞る

| 目的 | 選び方 |
| --- | --- |
| 最初の1冊 | 図・イラストが多く、1周を2〜3週間で読み切れるもの |
| 問題演習 | 過去問を分野別・ランダムに解けるサイトやアプリ |
| 公式情報 | 試験日程・出題範囲・最新の変更は必ず公式で確認 |

教材を増やすほど、どれも中途半端になります。**1つを3周**する方が合格に近づきます。勉強の進め方は「[おすすめの勉強方法](https://itbibliotheque.wordpress.com/?name=study-methods)」を参照してください。

## ベンダー資格（AWS・Linux・Oracle・Java）

| 資格 | 教材 | 使い方 |
| --- | --- | --- |
| AWS | [AWS Skill Builder](https://skillbuilder.aws/) | AWS公式の学習サイト。公式の練習問題で本番の形式を確認する |
| AWS | [Udemy](https://www.udemy.com/) のSAA-C03向け日本語講座・模擬試験 | 評価と受講者数の多い講座を1本。セール時に買う |
| AWS | SAA-C03対応の教科書（インプレス『徹底攻略』シリーズ、SBクリエイティブ『AWS認定資格試験テキスト』など） | 動画で一周した後の確認用 |
| Linux | [LinuC（LPI-Japan）](https://linuc.org/) の『Linux標準教科書』（無料） | Linuxの基礎を無料で学べる。サーバー作業の入門にも |
| Linux・Oracle・Java・ネットワーク | [Ping-t](https://ping-t.com/) | 問題演習サイト。LinuC/LPIC、ORACLE MASTER、Java、CCNAなどに対応 |
| Java | 『徹底攻略 Java SE Silver 問題集』（インプレス） | 通称「紫本」。Java Silver の定番問題集 |

ベンダー資格の試験は改訂されることがあります。**試験コード（例: SAA-C03）が教材と一致しているか**を必ず確認してください。

## 実務で長く使える定番の技術書

資格の勉強で土台ができたら、現場の仕事に直結する本を読むと、レビューや設計での発言が変わります。

| 分野 | 本 | こんな人に |
| --- | --- | --- |
| コードの書き方 | 『リーダブルコード』（オライリー・ジャパン） | コードレビューで指摘が多い人。新人のうちに読む1冊 |
| 仕事の進め方 | 『達人プログラマー』（オーム社） | 2〜3年目。自分の仕事の進め方を見直したい人 |
| データベース | 『SQLアンチパターン』（オライリー・ジャパン） | テーブル設計・SQLでやってはいけないことを知りたい人 |
| ネットワーク | 『ネットワークはなぜつながるのか』（日経BP） | ブラウザからサーバーまで、通信の流れを一通り理解したい人 |
| インフラ全般 | 『絵で見てわかる』シリーズ（翔泳社） | OS・ネットワーク・ストレージの仕組みを図で理解したい人 |
| Linux | 『［試して理解］Linuxのしくみ』（技術評論社） | プロセス・メモリ・ファイルシステムの動きを実際に試して理解したい人 |

## 困ったときに頼れるサイト

| サイト | 使い方 |
| --- | --- |
| 各技術の公式ドキュメント | エラーメッセージや仕様の確認は、まず公式。バージョンを合わせて読む |
| [Qiita](https://qiita.com/) / [Zenn](https://zenn.dev/) | 現場のエンジニアが書いた手順やハマりどころ。**投稿日とバージョン**を確認して使う |
| [IT Bibliotheque!](/) の技術まとめ・チートシート | 現場でよく使う技術のコマンド・エラー対応を1ページで確認できる |
| [確かめよう労働条件（厚生労働省）](https://www.check-roudou.mhlw.go.jp/) | 残業・休日・残業代など、働き方の決まりを確認するとき |
| [e-Gov法令検索](https://laws.e-gov.go.jp/) | 労働基準法などの条文を確認するとき |

働き方の決まりは、このサイトの「キャリア・働き方」でも解説しています。例えば「[36協定を結んでいたら何時間まで働ける？](https://itbibliotheque.wordpress.com/?name=saburoku-kyotei-overtime-limit)」や「[割増賃金の計算方法](https://itbibliotheque.wordpress.com/?name=overtime-premium-pay)」です。

## 教材を選ぶときのチェックリスト

- [ ] 受験する**年度・試験バージョン**（例: SAA-C03）に対応した版である
- [ ] 最初の1冊は、2〜3週間で1周できる厚さ・図の多さである
- [ ] 問題演習の教材は1つに絞った
- [ ] 試験日程・出題範囲は、公式サイトで確認した
- [ ] 会社の書籍購入補助・学習サービスの法人契約がないか確認した

## まとめ

- 教材は「**入門書1冊＋問題演習1つ＋公式**」に絞り、**1つを3周**する
- 書籍は毎年改訂されるので、**受験する年度・バージョンの版**を選ぶ
- 資格の後は、『リーダブルコード』『SQLアンチパターン』など**現場で長く使える本**で実務力につなげる
