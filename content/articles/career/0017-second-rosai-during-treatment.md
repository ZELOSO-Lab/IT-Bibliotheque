# 【労務】労災の治療中に2回目の労災。どうする？ 請求書は災害ごとに別、同じ部位の再負傷・通院途中の事故・休業給付の重なりの考え方

> **最終確認日: 2026年10月28日**（労働者災害補償保険法・同施行規則、労働基準法、労働安全衛生規則、厚生労働省・各労働局の公表資料で確認）。2つの災害が重なったときの扱いは、けがの部位・経緯・医師の所見によって個別に判断されます。この記事は考え方の整理です。手続きの前に、必ず所轄の労働基準監督署に相談してください。

## 現場の声

通勤中に駅の階段で転んで右手首を痛め、労災（通勤災害）で整形外科に通っていました。サポーターをしたまま出社していた3週間目、客先のフロアで床のケーブルに足を取られて、また転倒。今度は左ひざを打ちました。

病院で「前回の労災の書類で一緒に診てもらえばいいのかな」と考えたものの、1回目は通勤中、2回目は仕事中。書類が同じでいいはずがありません。

結論から言うと、**2回目は原則として「別の災害」**です。1回目の手続きはそのまま続け、2回目は**新しい災害として、請求書を一式あらためて出します**。

## 結論：3つのことを分けて考える

| 考えること | 答え |
| --- | --- |
| 1回目の手続きはどうなる？ | **そのまま続ける**。2回目が起きても止まらない |
| 2回目の手続きは？ | **新しい災害として別に請求**する。業務災害か通勤災害かで様式が違う |
| 病院では？ | 同じ病院でも「**労災が2件あります**」と伝え、請求書を**災害ごと**に出す |

迷うのは、次のような「どちらの災害とも言える」ケースです。

| ケース | 考え方 |
| --- | --- |
| 治療中の**同じ部位**を、新しい事故でまたけがした | 新しい事故として請求するのが基本。ただし「1回目の悪化」か「新しいけが」かは、医師の所見をもとに労基署が判断する |
| 1回目のけが（松葉杖・サポーター）が原因で転んだ | 1回目のけがとの**因果関係**が認められれば、**1回目の災害の療養の範囲**として扱われることがある |
| 労災の病院へ**通院する途中**で事故にあった | 通院のための移動は「通勤」ではないため、**原則として通勤災害にはならない** |
| 2つの災害で、同じ日に仕事を休んだ | 同じ日の休業について**二重に受け取れるとは考えない**。どちらで請求するか労基署に相談する |

## 前提：2回目は「業務災害」か「通勤災害」か

最初に、**2回目がどちらの災害か**を確認します。1回目と同じとは限りません。

| 2回目のけが | 区分 | 治療費の様式 | 休業の様式 |
| --- | --- | --- | --- |
| 仕事中（客先のフロア、作業中、出張中など） | **業務災害** | 様式第5号（指定外は第7号） | 様式第8号 |
| 出勤・退勤の途中 | **通勤災害** | 様式第16号の3（指定外は第16号の5） | 様式第16号の6 |

- 業務災害と通勤災害では、**会社の義務**も違います（待期3日間の休業補償、解雇制限、労働者死傷病報告など。後述）
- SES・常駐で、客先のフロアでけがをした場合も、手続きをするのは**雇用主である自社**です

通勤災害の基本の手続きは「[通勤中に転倒して病院へ。労災（通勤災害）でやるべきこと](/articles/commute-injury-rosai)」にまとめています。

## 当日にやること

| 順番 | やること |
| --- | --- |
| 1 | 病院の受付で「**前回の労災とは別に、今日また労災でけがをしました**」と伝える。健康保険証は出さない |
| 2 | 医師に、**1回目のけがの部位・経過**と、**今回の事故の状況**を両方伝える |
| 3 | 当日中に自社へ報告する。「2回目」であること、1回目との関係（部位が同じか、1回目のけがが原因か）を書く |
| 4 | 日時・場所・状況・写真・目撃者を記録する |
| 5 | 2回目用の請求書に事業主の証明をもらい、病院に提出する |

### 病院で伝えること

```text
○月○日の通勤災害で、右手首を治療中です（労災の書類は提出済み）。
今日、仕事中に客先で転倒し、左ひざを打ちました。こちらは業務災害です。
前回とは別の労災として、書類は後日提出します。
```

同じ病院・同じ日に両方を診てもらう場合でも、病院は**災害ごとに**診療報酬を請求します。受付で2件あることを伝えておくと、会計の混乱を防げます。

### 会社への報告

```text
件名: 2件目の負傷のご報告（業務中）

△△です。○月○日の通勤災害（右手首）で通院中ですが、
本日10:15頃、客先フロアで床のケーブルに足を取られて転倒し、左ひざを負傷しました。
□□整形外科で「左ひざ打撲、全治1週間」の診断です。
前回とは別の業務災害として、手続きをお願いします。
なお、今回の転倒と右手首のけがとの関係はありません（右手はついていません）。
```

最後の1行のように、**1回目との関係**を自分の言葉で書いておくと、会社も労基署も判断しやすくなります。

## ケース別の考え方

### 1. 別の部位の、新しいけが

もっとも単純なケースです。**完全に別の災害**として請求します。

- 1回目の療養は続く。2回目の療養も別に始まる
- 2つの請求書が並行して動く

### 2. 治療中の同じ部位を、またけがした

「治りかけの右手首を、また転んでついた」ような場合です。

- 新しい事故（転倒）があったので、**新しい災害として請求する**のが基本です
- ただし、医師が「新しいけがではなく、**1回目のけがの悪化**」と判断すると、1回目の災害の療養として扱われることもあります
- どちらで扱うかで、給付基礎日額（業務災害か通勤災害か、いつの賃金で計算するか）や、会社の義務が変わることがあります

自分で決めずに、**医師に経緯を正確に伝え**、労基署に「同じ部位を再度負傷した。どちらの請求で出すべきか」と相談してください。

### 3. 1回目のけがが原因で、2回目が起きた

「足のけがで松葉杖をついていて、駅の階段で転んだ」ような場合です。

- 1回目のけがと**相当因果関係**（そのけががなければ起きなかった、と言える関係）があれば、2回目のけがも**1回目の災害の療養の範囲**として扱われることがあります
- 逆に、松葉杖とは関係なく他人にぶつかられて転んだ、などの場合は新しい災害です

これも個別判断です。「松葉杖で階段を下りていて、杖が滑った」のように、**1回目のけががどう関わったか**を具体的に記録しておきます。

### 4. 労災の病院に通院する途中の事故

「仕事を休んで、自宅から整形外科に通う途中で転んだ」場合です。

- 通勤災害の「通勤」は、**就業のための**住居と職場の間の移動です。通院だけのための移動は通勤に当たらないため、**原則として通勤災害にはなりません**
- 一方、**出勤途中や退勤途中に病院へ寄り**、診察を終えて**通常の経路に戻った後**の事故は、通勤災害になり得ます（病院での診察は「日常生活上必要な行為」）。病院に向かって経路を外れている間と、病院にいる間は対象外です
- 通院途中の事故でも、1回目のけがが原因（ケース3）なら、1回目の災害の療養の範囲として扱われる可能性があります

## 休業が重なったとき

### 同じ日の休業は二重にならない

休業(補償)給付は、けがで**働けず、賃金を受けない日**に対する給付です。1回目でも2回目でも働けない日があったとしても、**同じ日について2件分を重ねて受け取れるとは考えないでください**。

- 1回目で休業中に2回目が起きた、2回目で休業が延びた、という場合は、**どちらの災害で休業を請求するか**を労基署に相談します
- 給付基礎日額は災害ごとに計算されるため、どちらで請求するかで金額が変わることがあります

### 2回目の給付基礎日額が低くなりすぎないか

給付基礎日額は、原則として**けがをした日の直前3か月の賃金**から計算します（労働基準法の平均賃金）。1回目の休業で賃金が少なかった期間が含まれると、低くなりすぎるおそれがあります。

- **業務上のけがで療養のために休業した期間**は、平均賃金の計算期間から**除かれます**（労働基準法 第12条第3項第1号）
- 1回目が通勤災害だった場合など、それ以外の事情がある場合の計算は、労基署に確認してください

### 待期3日間

休業給付は、**災害ごとに**最初の3日間が待期期間です。

- 2回目が**業務災害**なら、待期3日間は**会社が休業補償**（平均賃金の60%以上）をする義務があります（労働基準法 第76条）
- 2回目が**通勤災害**なら、その義務はありません。年次有給休暇の利用を検討します

## 会社側の義務：業務災害か通勤災害かで変わる

| 会社の義務 | 業務災害 | 通勤災害 |
| --- | --- | --- |
| 待期3日間の休業補償（労働基準法 第76条） | **あり** | なし |
| 療養のための休業中と、その後30日間の解雇制限（労働基準法 第19条） | **あり** | なし |
| 労働者死傷病報告の提出（労働安全衛生規則 第97条） | **あり**（休業4日以上は遅滞なく。2025年1月から原則電子申請） | なし |
| 請求書の事業主証明 | あり | あり |

- 労働者死傷病報告は、**災害ごと**に提出します。2回目が業務災害で4日以上休むなら、会社は2回目の分を提出します
- 会社が「2回目は労災にしないで」と言っても、労災の請求は**本人ができます**。業務災害を報告しないことは「**労災かくし**」として法違反になります

## 後遺障害が残った場合：「加重」の考え方

治療が終わって障害が残った場合、障害(補償)給付を請求します。

- 2つの災害で**別の部位**に障害が残った場合は、それぞれの障害を合わせて等級が決まります（併合）
- 1回目ですでに障害が残っていた部位に、2回目で障害が**重くなった**場合は「**加重**」として、重くなった分が給付の対象になります（労働者災害補償保険法施行規則 第14条第5項）

## 2回目を防ぐために

治療中は、普段より転びやすく、けがをしやすい状態です。

| 対策 | 具体的に |
| --- | --- |
| 医師に**就業上の配慮**の意見をもらう | 「階段の多い通勤経路を避ける」「重い物を持たない」「在宅勤務が望ましい」など。診断書や意見書にしてもらう |
| 会社に配慮を求める | 会社には安全配慮義務がある（労働契約法 第5条）。SES・常駐なら、自社の営業から客先に伝えてもらう |
| 通勤を変える | 時差出勤、エレベーターのある駅・出口を使う、雨の日は早めに出る |
| 職場の危険を報告する | 2回目の原因（床のケーブルなど）は、自社経由で客先に改善を依頼する。次の人のけがを防ぐ |
| 無理をしない | 「迷惑をかけたくない」と痛みを我慢して出社すると、治りが遅れ、2回目のリスクも上がる |

## まとめ

- 2回目は原則として**別の災害**。1回目の手続きは続け、**2回目の請求書を一式あらためて出す**
- **業務災害か通勤災害か**で、様式も会社の義務も変わる
- 同じ部位の再負傷、1回目のけがが原因の転倒、通院途中の事故は**個別判断**。記録を残し、労基署に相談する
- 休業は**同じ日に二重に受け取れない**と考え、どちらで請求するかを相談する
- 治療中は医師に**就業上の配慮**の意見をもらい、2回目を防ぐ

困ったときは、所轄の労働基準監督署（労災課）、または総合労働相談コーナーに相談できます。
