# 【メンタル】「笑わなきゃ」をやめる。追い込まれた時のメンタルケアの習慣と、悪い方に考えてしまう癖のほどき方

> この記事はセルフケアの方法の紹介で、医療的な診断や治療の代わりにはなりません。眠れない・気分の落ち込みが2週間以上続く場合は、「[高稼働で追い込まれた時に最初にやること](/articles/overwhelmed-first-aid)」の目安を見て、医師・専門家に相談してください。

## 現場の声

稼働が高い時期、職場では意識して笑うようにしていました。

「暗い顔をしていたら、周りに気を使わせる」「感じが悪いと思われたら契約に響く」

そう考えて、話しかけられるたびに笑顔を作っていました。ところが、帰りの電車でどっと疲れが出て、家に着くと何もできません。リーダーから「フォローに入るね」と言われた日は、「力不足だと思われている」と一晩中考えていました。

今思えば、**笑顔を作ること自体が、残り少ない体力を削っていました**。そして、寝不足の頭で考えた「責められている」は、事実ではなく**自分の解釈**でした。

## 結論

| やめること | 代わりにやること |
| --- | --- |
| 「笑わなきゃ」と常に明るくふるまう | **挨拶・お礼・返事**の3つを丁寧にするだけで十分とする |
| 頭の中で「どう思われているか」を考え続ける | **事実と解釈を紙に分けて書く**（3列メモ） |
| 「できなかったこと」を数えて寝る | 寝る前に**「やったこと」を3つ**書く |
| 休日も仕事の不安を抱えて過ごす | **仕事のことを考えない時間**を予定に入れる |

## 1. 作り笑いをやめても、職場では困らない

本心と違う表情を作り続けることは、心理学で「感情労働」と呼ばれ、続けると疲れがたまりやすいことが知られています。追い込まれている時ほど、笑顔に使う力を回復に回します。

職場で信頼されるのに必要なのは、笑顔よりも**次の3つ**です。

| ふるまい | 具体例 |
| --- | --- |
| 挨拶 | 朝・帰りに相手の方を見て「おはようございます」「お先に失礼します」 |
| お礼 | 教えてもらった、手伝ってもらった時に「ありがとうございます、助かりました」 |
| 返事 | 依頼に「承知しました。○日までに対応します」と期限つきで返す |

この3つができていれば、表情が硬くても「感じが悪い人」とは受け取られにくくなります。無理に雑談を盛り上げる必要もありません。

どうしても表情が気になる時は、**口角を少し上げるだけ**で十分です。声を出して笑う必要はありません。

## 2. 「悪い方に考えてしまう」癖に名前をつける

追い込まれている時は、物事を悪い方向に解釈しやすくなります。認知行動療法では、このような考え方の偏りを「認知の歪み」と呼び、いくつかの型に分けています。自分の考えがどの型か分かるだけで、少し距離を置けます。

| 型 | 考え方の例 | 別の見方の例 |
| --- | --- | --- |
| **心の読みすぎ** | 話しかけたら静かになった。自分が嫌われている | 話題が身内の話で、説明が面倒だっただけかもしれない |
| **先読み** | このままだと契約を切られる | まだ何も言われていない。言われてから動いても間に合う準備はできる |
| **自己関連づけ** | リーダーがフォローに入るのは、自分の力不足のせい | 遅延時に人を増やすのはリーダーの通常の仕事。スケジュールの問題でもある |
| **すべき思考** | いつも明るくしなければならない | 挨拶・お礼・返事ができていれば十分 |
| **全か無か** | 1つ遅れたから、自分は全部だめだ | 遅れたのは1件。ほかの作業は進んでいる |

## 3. 事実と解釈を分ける「3列メモ」

頭の中で同じことを考え続けてしまう時は、紙かメモアプリに次の3列で書き出します。認知行動療法の「コラム法」を簡単にしたものです。

| 起きたこと（事実） | 頭に浮かんだ考え（解釈） | ほかの可能性 |
| --- | --- | --- |
| 雑談中の2人に話しかけたら、会話が止まった | 自分は歓迎されていない | 2人とも作業に戻るタイミングだった。自分に向けた反応とは限らない |
| リーダーに「来週から○○さんがフォローに入る」と言われた | 力不足だと責められている | 期限を守るための人員調整。責める言葉は言われていない |
| 自分が出ていない会議で、遅延の話が出たらしい | 自分のせいにされているに違いない | 何が話されたかはまだ分からない。確認すればよい |

書くときのコツです。

- **1列目には、録画していたら映る事実だけ**を書く。「冷たくされた」は解釈なので2列目に書く
- 3列目は、**正解を探さなくてよい**。可能性を1つ書ければ十分
- 3列目に「**確認すればよい**」と書けたら、次の行動が決まる（確認の仕方は「[会話に入れない・会議で何を言われているか分からない時の、事実記録と報告の型](/articles/isolation-and-reporting)」で紹介します）

それでも考えが止まらない、または同じ考えが何日も頭から離れない場合は、医療機関で相談してください。認知行動療法は、医師やカウンセラーのもとで本格的に受けることもできます。

## 4. 毎日5分でできるケアの習慣

| タイミング | 習慣 | 時間 |
| --- | --- | --- |
| 朝 | 起きたら窓を開けて外の光を浴びる | 1分 |
| 昼 | 昼休みは席を離れる。外を5分歩く | 5分 |
| 帰り | 会社を出たら、社用チャットの通知を切る | 10秒 |
| 寝る前 | 「今日やったこと」を3つ書く（「メールを返した」程度でよい） | 2分 |
| 週1回 | 仕事と関係ない人（家族・友人）と話す | 30分〜 |

「やったこと」は小さくてかまいません。追い込まれている時は「できなかったこと」ばかり数えてしまうので、**意識して逆を数える**ことが目的です。

休日には、**仕事のことを考えない時間**を予定として入れます。「午後は映画」「朝は散歩」のように、具体的に決めておくと守りやすくなります。

## 5. 1人で抱えないための相手を決めておく

話す相手は、立場ごとに分けておくと迷いません。

| 相手 | 話すこと |
| --- | --- |
| 家族・友人 | 気持ち。解決策はいらないので、聞いてもらう |
| 自社の上長・営業 | 業務量・稼働時間・契約に関すること |
| 医師・カウンセラー | 眠れない、気分が落ち込む、考えが止まらない |
| 外部の相談窓口 | 誰にも言いにくい時。匿名で相談できる |

職場の同僚にすべてを打ち明ける必要はありません。職場では「業務の話ができる関係」があれば十分です。

## まとめ

- 作り笑いは体力を削る。職場の信頼は**挨拶・お礼・返事**で十分に保てる
- 悪い方に考えた時は、**考え方の型に名前をつけて**距離を置く
- 頭の中で考え続けず、**事実・解釈・ほかの可能性**の3列に書き出す
- 毎日5分のケアで、**「やったこと」を数える**習慣をつける
- 考えが止まらない状態が続くなら、医療機関に相談する
