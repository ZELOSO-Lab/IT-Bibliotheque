# 【働き方】契約を切られるのが怖い時の備え。SES・常駐で「案件終了」と「解雇」は別もの、自社営業への相談の仕方と、選択肢を確保する手順

> **最終確認日: 2026年10月21日**（労働基準法・労働契約法・民法、e-Gov法令検索で確認）。一般的な決まりの解説です。自分のケースに当てはまるかは、雇用契約書・就業規則を確認したうえで、総合労働相談コーナーなどの窓口に相談してください。

## 現場の声

作業の遅れが続き、リーダーがフォローに入ることになりました。その日から、頭の中は1つのことでいっぱいでした。

「次の契約更新で、切られるかもしれない」

切られたらどうなるのか。給料はどうなるのか。次の現場はあるのか。何も分からないまま、夜中に目が覚めては同じことを考えていました。

調べて分かったのは、**自分が「切られる」と思っていたのは、会社同士の契約だった**ということです。そして、自社の営業に早めに相談していれば、不安の大半はもっと早く小さくできていました。

## 結論

| 不安 | 知っておくこと・やること |
| --- | --- |
| 契約を切られたら仕事を失う | SES・常駐の正社員なら、終わるのは**会社同士の契約（案件）**。自社との**雇用契約は続く** |
| 次の現場が決まるまで給料が出ない | 会社の都合で休ませる場合、会社は**平均賃金の60%以上の休業手当**を支払う義務がある（労働基準法第26条） |
| いつ切られるか分からない | 自社の営業に、**契約期間・更新時期・常駐先の評価**を聞く |
| 切られたら終わり | 今のうちに**スキルシート・貯蓄・選択肢**を整えておく |

## 1. まず、自分の契約の形を確認する

「契約を切られる」の意味は、契約の形によって変わります。次の2つを確認します。

### 自社と常駐先の契約（会社同士）

| 契約の形 | 特徴 | 作業の指示を出すのは |
| --- | --- | --- |
| 準委任契約（SESに多い） | 作業の遂行に対して報酬が払われる。成果物の完成義務はない | **自社**（常駐先が直接指示するのは原則不可） |
| 請負契約 | 成果物の完成に対して報酬が払われる | **自社** |
| 労働者派遣契約 | 派遣元が雇用し、派遣先が指示する | **常駐先（派遣先）** |

### 自分と自社の契約（雇用）

| 雇用の形 | 案件が終わったとき |
| --- | --- |
| 正社員（期間の定めなし） | 雇用は続く。自社が次の案件を探す |
| 契約社員（期間の定めあり） | 契約期間中は原則として雇用が続く。更新されるかは契約次第 |
| 個人事業主（フリーランス） | 雇用ではないため、案件の終了がそのまま収入の終了になる |

雇用契約書（労働条件通知書）と就業規則を確認し、自分がどれに当たるかを把握しておきます。

## 2. 「案件終了」と「解雇」は別もの

SES・常駐の正社員の場合、常駐先が契約を更新しないことは**会社同士の契約の終了**です。あなたと自社の雇用契約が終わるわけではありません。

| 項目 | 決まり | 根拠 |
| --- | --- | --- |
| 解雇の制限 | 客観的に合理的な理由がなく、社会通念上相当と認められない解雇は無効 | 労働契約法第16条 |
| 解雇の予告 | 解雇するには、少なくとも30日前に予告するか、30日分以上の平均賃金（解雇予告手当）を払う | 労働基準法第20条 |
| 契約期間中の解雇（有期） | 期間の定めがある場合、やむを得ない事由がなければ期間中に解雇できない | 労働契約法第17条 |
| 待機中の給与 | 会社の責任による休業では、平均賃金の60%以上の休業手当を払う | 労働基準法第26条 |

- 案件が終わって次の案件が決まるまでの「待機」でも、正社員なら**給与が全額支払われる会社も多い**です。扱いは会社によって違うので、就業規則で確認するか、自社に聞いておきます
- 「案件が終わったから」という理由だけで、ただちに解雇が認められるわけではありません。不安な場合は総合労働相談コーナーに相談できます

## 3. 契約終了は、ふつう突然ではない

会社同士の準委任契約は、**1〜3か月単位で更新**されることが多く、更新しない場合は**1か月前までに通知する**などの取り決めがあるのが一般的です（具体的な期間は契約によって違います）。

民法上、準委任契約はいつでも解除できますが、相手に不利な時期に解除した場合などは損害賠償の対象になります（民法第651条、第656条）。そのため実務では、契約期間と更新の通知期限を決めて運用するのが普通です。

つまり、**次の更新月と通知期限が分かれば、「いつまでは大丈夫か」が分かります**。これを知るだけで、毎日の不安はかなり小さくなります。

## 4. 自社の営業に相談する

常駐先との契約の窓口は、**自社の営業（または上長）**です。常駐先の評価や更新の見込みは、自社の営業が一番よく知っています。

### 聞くこと

```text
お疲れさまです。○○（常駐先）の件でご相談です。

現在、作業の遅延が続いており、リーダーがフォローに入る体制になりました。
（進捗報告を添付します）

今後の見通しを持って働きたいので、以下を教えていただけますか。
1. 現在の契約期間と、次の更新時期・更新の通知期限
2. 常駐先から、私の作業について何か言われていることがあるか
3. 契約が更新されなかった場合の流れ（待機中の扱い、次の案件の探し方）

また、稼働が高い状態が続いており（今月の残業 約○時間、休日出勤 ○日）、
体制や作業量について常駐先と調整いただけると助かります。
```

- **進捗報告や作業ログを添える**。事実が分かれば、営業は常駐先に正しく説明できます（記録の付け方は「[会話に入れない・会議で何を言われているか分からない時の、事実記録と報告の型](/articles/isolation-and-reporting)」を参照してください）
- **稼働の高さも伝える**。稼働の調整は、契約の窓口である営業の仕事です
- 聞いた内容はメモに残します

「切られるかもしれない」と自分から言うのは怖いことですが、**営業が知らないまま更新時期を迎えるほうが危険**です。早く共有するほど、営業が打てる手（体制の調整、作業範囲の見直し、次の案件の準備）が増えます。

## 5. 今のうちに選択肢を確保する

不安を小さくする一番の方法は、「**切られても次がある**」状態を作っておくことです。

| 準備 | やること | 時間 |
| --- | --- | --- |
| スキルシートの更新 | 今の案件の内容（言語・工程・役割・規模）を書き足す | 30分 |
| 次の案件の希望を伝える | 自社の営業に「次に経験したい技術・工程」を伝えておく | 10分 |
| 生活防衛資金の確認 | 生活費の何か月分の貯蓄があるか計算する。目安は3〜6か月分 | 15分 |
| 市場の確認 | 転職サイトに登録だけして、自分の経験でどんな求人があるかを見る | 30分 |
| 学習の準備 | 次の案件や転職で評価される資格を1つ決める | 15分 |

- 転職サイトへの登録は、**すぐに転職するためではなく、選択肢があることを確認するため**です。求人を見るだけで「今の現場がすべてではない」と分かり、気持ちが軽くなります
- 資格の選び方は「[エンジニアの資格はどれを取る？](/articles/it-certifications-guide)」、働きながらの勉強法は「[おすすめの勉強方法](/articles/study-methods)」で紹介しています。ただし、**眠れていない時期に勉強を詰め込む必要はありません**。準備は「決めておく」だけで十分です

## 6. 「最悪の場合」を紙に書いて終わらせる

不安が頭の中で大きくなるのは、「最悪の場合どうなるか」がはっきりしないからです。一度、紙に書き出して終わらせます。

```text
最悪の場合: 次の更新（12月末）で常駐先の契約が終わる
→ そうなったら: 自社で待機。給与は就業規則のとおり（営業に確認済み）
→ その間にやること: 次の案件の面談、スキルシートの更新
→ 自社に次の案件がなかったら: 転職活動。貯蓄は生活費○か月分ある
→ 結論: 困るが、生活が止まるわけではない
```

最後まで書くと、「最悪の場合でも、取れる行動がある」ことが分かります。書いた紙は、不安になった時に読み返します。

## まとめ

- SES・常駐の正社員なら、終わるのは**会社同士の契約**。自社との**雇用は続く**
- 会社都合の待機には、少なくとも**平均賃金の60%以上の休業手当**がある（労働基準法第26条）
- 契約終了はふつう突然ではない。**更新時期と通知期限**を自社の営業に聞く
- 事実の記録を添えて**早めに自社の営業に相談**するほど、打てる手が増える
- スキルシート・貯蓄・市場の確認で、「**切られても次がある**」状態を作る

このシリーズの最初の記事「[高稼働で追い込まれた時に最初にやること](/articles/overwhelmed-first-aid)」もあわせて読んでください。不安への備えは、眠れる状態を取り戻してからで間に合います。

## 根拠

- 労働基準法 第20条（解雇の予告）、第26条（休業手当）
- 労働契約法 第16条（解雇）、第17条（契約期間中の解雇等）
- 民法 第651条（委任の解除）、第656条（準委任）
