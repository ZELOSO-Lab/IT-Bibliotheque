# 【労務】割増賃金の計算方法。時間外25%・60時間超50%・休日35%・深夜25%の組み合わせと、給与明細の確かめ方

> **最終確認日: 2026年10月19日**（労働基準法・同施行規則・e-Gov法令検索、厚生労働省の公表資料で確認）。法改正で変わることがあります。

## 現場の声

障害対応が続いた月、残業は70時間を超えました。深夜の切り戻し作業や、日曜の本番作業もありました。ところが、給与明細の残業代は思ったより少なく、どこで計算がずれているのか分かりません。

確認すると、原因は次の3つでした。

- **月60時間を超えた分の50%**が反映されていなかった
- 深夜（22時〜5時）の割増が、時間外の25%と**別に加算**されていなかった
- 1時間あたりの賃金を、**手当を除いた基本給だけ**で計算していた

割増賃金は「率」と「1時間あたりの賃金」の両方が合っていないと、正しい金額になりません。順番に整理します。

## 結論：割増率の一覧

| 働き方 | 割増率（以上） | 根拠 |
| --- | --- | --- |
| 時間外労働（1日8時間・週40時間を超えた分） | **25%** | 第37条第1項、割増賃金令 |
| 時間外労働のうち**月60時間を超えた分** | **50%** | 第37条第1項ただし書 |
| 休日労働（法定休日） | **35%** | 第37条第1項、割増賃金令 |
| 深夜労働（22時〜翌5時） | **25%** | 第37条第4項 |
| 時間外＋深夜 | **50%**（25%＋25%） | |
| 月60時間超の時間外＋深夜 | **75%**（50%＋25%） | |
| 休日＋深夜 | **60%**（35%＋25%） | |

- 月60時間超の50%は、2023年4月から**中小企業にも適用**されています。
- **法定休日の労働に「時間外」はありません**。法定休日に10時間働いても35%です（深夜帯は60%）。
- 法定休日の労働時間は、**月60時間の計算に含めません**。所定休日（例: 土曜）の労働で週40時間を超えた分は時間外労働なので**含めます**。法定休日と所定休日の違いは「[法定休日とは？](https://itbibliotheque.wordpress.com/?name=legal-holiday)」を参照してください。
- 所定労働時間（例: 7.5時間）を超え、8時間以内の「法内残業」は、法律上の割増は不要です（通常の賃金は必要。会社の規定で割増を付ける場合もあります）。

## 1時間あたりの賃金の出し方

月給制の場合、1時間あたりの賃金は次の式で計算します（労働基準法施行規則 第19条）。

```text
1時間あたりの賃金 ＝ 月給（除外できる手当を除く）÷ 1か月平均所定労働時間
1か月平均所定労働時間 ＝ 年間所定労働日数 × 1日の所定労働時間 ÷ 12
```

### 除外できる手当は7つだけ

計算の基礎から除外できるのは、次の7つに限られます（第37条第5項、施行規則 第21条）。

1. 家族手当
2. 通勤手当
3. 別居手当
4. 子女教育手当
5. 住宅手当
6. 臨時に支払われた賃金
7. 1か月を超える期間ごとに支払われる賃金（賞与など）

- **職務手当・資格手当・役職手当・技術手当などは除外できません**。基本給だけで計算していたら、少なく計算されています。
- 家族手当・通勤手当・住宅手当は、**名前ではなく実態**で判断します。例えば、扶養家族の人数に関係なく全員一律に支払う「家族手当」や、住宅の形態や費用に関係なく一律の「住宅手当」は除外できません。

## 計算例

**前提**

| 項目 | 内容 |
| --- | --- |
| 月給 | 基本給 270,000円＋職務手当 20,000円＋通勤手当 10,000円 |
| 計算の基礎 | 270,000＋20,000 ＝ **290,000円**（通勤手当は除外） |
| 年間所定労働日数 | 240日（年間休日125日）、1日8時間 |
| 1か月平均所定労働時間 | 240 × 8 ÷ 12 ＝ **160時間** |
| 1時間あたりの賃金 | 290,000 ÷ 160 ＝ **1,812.5円** |

**この月の働き方**

- 時間外労働 70時間（うち深夜 5時間）
- 法定休日の労働 8時間（深夜なし）

**計算**

| 内訳 | 計算 | 金額 |
| --- | --- | --- |
| 時間外 60時間まで | 1,812.5 × 1.25 × 60 | 135,937.5円 |
| 時間外 60時間超（10時間） | 1,812.5 × 1.50 × 10 | 27,187.5円 |
| 深夜の加算（5時間） | 1,812.5 × 0.25 × 5 | 2,265.6円 |
| 休日労働（8時間） | 1,812.5 × 1.35 × 8 | 19,575円 |
| **合計** | | **約184,966円** |

- 深夜の時間が時間外労働の中にある場合、時間外分（1.25または1.5）に**深夜の0.25を加算**します。
- 60時間を超えた後の深夜は、1.5＋0.25＝**1.75倍**になります。

## 端数処理で認められること・認められないこと

| 処理 | 可否 |
| --- | --- |
| 1か月の時間外・休日・深夜の**それぞれの合計**で、30分未満を切り捨て、30分以上を1時間に切り上げ | 認められる |
| 1時間あたりの賃金・割増賃金の1円未満を四捨五入 | 認められる |
| **毎日**の残業を15分単位・30分単位で切り捨て | **認められない**（1分単位で数える） |

## 固定残業代（みなし残業）の注意点

給与に「固定残業代（○時間分）」が含まれている場合も、次の点は変わりません。

- 固定残業代は、**何時間分・いくらか**が通常の賃金と区別して明示されている必要があります。
- 実際の割増賃金が固定残業代を**超えた分は、差額の支払いが必要**です。
- 深夜・休日・60時間超の割増も、固定残業代でカバーされていなければ別に必要です。

## 給与明細のチェックリスト

- [ ] 1時間あたりの賃金に、**職務手当・資格手当**などが含まれている
- [ ] 月60時間を超えた時間外労働に**50%**が付いている
- [ ] 22時〜5時の作業に、深夜の**25%が別に加算**されている
- [ ] 法定休日の出勤に**35%**が付いている（代休を取っていても必要）
- [ ] 残業時間が**日ごとに切り捨て**られていない
- [ ] 固定残業代の時間数を超えた月に、**差額**が支払われている

自分の勤怠記録（PCのログオン・ログオフ、入退館記録、作業メモ）を残しておくと、明細と突き合わせられます。未払いの賃金は、支払日から**3年**（当分の間）で時効になります（第115条、附則第143条）。

## まとめ

- 割増率は、時間外**25%**、60時間超**50%**、休日**35%**、深夜**25%**。深夜は他の割増に**加算**する
- 1時間あたりの賃金から除外できるのは**7つの手当だけ**。職務手当などは含める
- 残業は**1分単位**で数える。月の合計での30分単位の丸めは可、日ごとの切り捨ては不可

残業時間そのものの上限は「[36協定を結んでいたら何時間まで働ける？](https://itbibliotheque.wordpress.com/?name=saburoku-kyotei-overtime-limit)」を参照してください。
