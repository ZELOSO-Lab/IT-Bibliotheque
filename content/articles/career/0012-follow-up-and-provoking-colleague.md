# 【人間関係】「フォローに入る」と言われた時、「残業やばいっす」と煽られた時。言葉に振り回されない受け止め方と、距離の取り方

## 現場の声

作業が遅れ始めたころ、リーダーから言われました。

「来週から、自分もフォローに入るから」

ありがたいはずの言葉なのに、「お前だけでは無理だ」と言われた気がして、その日はずっと落ち込んでいました。

同じ時期、自社のメンバーの1人が、こんなことを言ってきました。

「最近残業と休出多くて、ストレスやばいっす〜」

勤務表を見る限り、その人の残業は自分よりずっと少ない。休日出勤が続いている自分の前でわざわざ言うのは、煽っているのか。返す言葉が見つからず、モヤモヤだけが残りました。

どちらも、**言葉そのものより、自分がどう受け取ったか**で苦しくなっていました。

## 結論

| 場面 | やること | やらないこと |
| --- | --- | --- |
| 「フォローに入る」と言われた | **範囲・期間・自分の役割**を確認して、次の行動に変える | 「責められた」と1人で解釈して落ち込む |
| 同僚に「残業やばいっす」と言われた | **短く返して会話を終える**。比較しない | 自分の残業時間を言い返す、張り合う |
| 同僚の言動が続いて仕事に影響する | **距離を取る**。実害があれば**事実を記録して上長へ** | 我慢し続ける、陰で愚痴を広げる |

## 1. 「フォローに入る」は、まず意味を確認する

リーダーが「フォローに入る」と言う理由は、いくつもあります。

| 理由 | よくある状況 |
| --- | --- |
| スケジュールを守るため | 遅れている作業に人を足すのは、リーダーの通常の仕事 |
| リスクを分けるため | 1人しか分からない作業は、その人が休むと止まる |
| 上から指示されたため | リーダー会や顧客から「体制を厚くして」と言われた |
| 負荷を下げるため | 残業が続いているのを見て、休ませようとしている |
| 力量に不安があるため | 進め方や品質に懸念がある |

最後の理由の可能性もありますが、それは**5つのうちの1つ**です。どれなのかは、聞かなければ分かりません。

### 確認の仕方

「なぜですか」と聞くと、身構えた印象になります。**次の行動を決めるための質問**として聞きます。

```text
ありがとうございます、助かります。
進め方を合わせたいので、確認させてください。

1. フォローいただく範囲は、どの作業になりますか
2. いつごろまでの予定ですか
3. その間、私は何を優先すればよいですか
4. 私の進め方で、直したほうがよい点があれば教えてください
```

- 1〜3で、**分担と自分の役割**がはっきりします。役割が決まれば「何をすればいいか分からない」不安がなくなります
- 4を聞いておくと、もし力量の懸念があった場合も、**何を直せばよいか**が具体的に分かります。指摘がなければ、それも1つの答えです
- 聞いた内容は作業ログに残します（作業ログの付け方は「[会話に入れない・会議で何を言われているか分からない時の、事実記録と報告の型](/articles/isolation-and-reporting)」を参照してください）

### 引き継ぐときのポイント

フォローの人に作業を渡すときは、**自分が進めた分が見える形**で渡します。

```text
○○機能 改修の引き継ぎ
・完了: 画面A・画面Bの改修、単体テスト（PCL No.1〜24）
・途中: 画面Cのエラー処理（残り: E0105 / E0106 の判定）
・未着手: 画面Dの改修
・注意点: △△テーブルの仕様は回答待ち（10/17 質問）
```

完了・途中・未着手を分けて書くと、「ここまでは自分が終わらせた」ことが自然に伝わります。

## 2. 「残業やばいっす」と言われた時の返し方

同僚の「残業やばいっす」には、いくつかの可能性があります。

- 本当にその人にとってはつらい（人によって負荷の感じ方は違う）
- 共感してほしい、話のきっかけがほしいだけ
- 自分の大変さをアピールしたい
- あなたを煽っている

どれであっても、**あなたの残業時間と比べる話ではありません**。比べて言い返すと、「どっちがつらいか」の張り合いになり、あなたの体力がさらに減ります。

### 反応しない返し方

| 返し方 | 例 |
| --- | --- |
| ねぎらって終える | 「お疲れさまです。無理しないでくださいね」 |
| 事実だけ受け取る | 「そうなんですね」 |
| 話題を業務に戻す | 「そういえば、○○の件ってどうなりました？」 |
| その場を離れる | 「すみません、ちょっと作業に戻ります」 |

ポイントは、**短く返して会話を終えること**です。相手の言葉の裏を読み取ろうとしたり、気の利いた返しを考えたりする必要はありません。

## 3. 距離の取り方

言動が続いてモヤモヤが消えない相手とは、仕事に支障がない範囲で距離を取ります。

| 距離 | やること |
| --- | --- |
| 物理的な距離 | 休憩・昼食の時間や場所をずらす。席替えの機会があれば希望を出す |
| 時間的な距離 | 話す時間を業務の連絡に限る。雑談に長く付き合わない |
| 情報の距離 | 自分の稼働・体調・契約の不安などを、その人には話さない |
| 気持ちの距離 | 「あの人はそういう言い方をする人」と決めて、言葉に意味を探さない |

距離を取ることは、相手を無視することではありません。**挨拶と業務の連絡は普通にする**。それ以上は求めない、という線引きです。

## 4. 実害がある時は、記録して上長に相談する

次のような場合は、我慢せずに自社の上長に相談します。

- 自分への嫌味・からかいが繰り返される
- 自分の仕事について、事実と違うことを周りに言っている
- 業務の連絡を意図的に止められるなど、仕事に影響が出ている

相談するときは、感想ではなく**事実を記録して**持っていきます。

```text
10/18（土）13:00ごろ　執務室にて
××さんから「最近残業と休出多くてストレスやばいっす〜」と言われた。
同様の発言は 10/11、10/15 にもあり、今回で3回目。
自分の休日出勤が続いている時期で、精神的に負担に感じている。
```

- **いつ・どこで・誰が・何を**を書く。「煽られた」ではなく、言われた言葉をそのまま書く
- 1回だけではなく、**繰り返されている**ことが分かるように日付を並べる
- 自分がどう感じたかは、最後に1行で書く

職場のいじめ・嫌がらせ（パワーハラスメントを含む）について、会社には相談窓口を設けるなどの対応が義務づけられています。社内で相談しにくい場合は、都道府県労働局の総合労働相談コーナーでも相談できます。

## まとめ

- 「フォローに入る」の理由は複数ある。**範囲・期間・自分の役割を確認**して、次の行動に変える
- 指摘を受けるなら、**何を直せばよいか具体的に聞く**。指摘がなければそれも答え
- 「残業やばいっす」は**比べずに短く返して終える**
- 合わない相手とは、**挨拶と業務連絡だけの距離**を取る
- 実害があれば、**言われた言葉と日時を記録**して自社の上長に相談する
