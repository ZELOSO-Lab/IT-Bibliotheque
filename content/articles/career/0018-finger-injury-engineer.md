# 【働き方】指をけがしてキーボードが打てない。応急処置と受診の目安、職場への報告、片手でも仕事を回す工夫、労災になるケース

> **最終確認日: 2026年11月25日**（労働者災害補償保険法、労働基準法、健康保険法、労働安全衛生規則、厚生労働省・東京消防庁の公表資料で確認）。応急処置は一般的な内容で、診断や治療の代わりにはなりません。けがの程度の判断は医師に、労災に当たるかどうかは所轄の労働基準監督署に確認してください。

## 現場の声

客先で届いたばかりの検証用PCの段ボールをカッターで開けていて、刃が滑りました。左手の人差し指から血が止まらない。とりあえずティッシュで押さえて席に戻ったものの、包帯を巻いた指ではキーボードのホームポジションに手が置けません。

頭に浮かんだのは「病院に行くほどかな」「今日のレビュー指摘、誰が直すんだろう」「これって労災？ 自分の不注意だし……」。

結論から言うと、

- **出血が止まらない・深い・しびれる**なら、迷わず受診します（目安は下の表）
- 仕事中のけがは、**自分の不注意でも労災（業務災害）**です。病院では健康保険証を出さず「仕事中のけがです」と伝えます
- 指が使えない間は、**音声入力・固定キー・スニペット**で入力量を減らし、**作業計画を引き直して早めに共有**するのが、自分もチームも一番楽になる方法です

## 結論：やることは5つ

| 順番 | やること | いつ |
| --- | --- | --- |
| 1 | **圧迫止血**して、傷を**流水で洗う**。受診の目安に当てはまれば受診する | 直後〜当日 |
| 2 | 病院の受付で、仕事中・通勤中なら「**労災でお願いします**」と伝える | 受診時 |
| 3 | **自社（と客先）に報告**する。けがの状況と、作業への影響の見込みをセットで | 当日中 |
| 4 | 入力を減らす設定（**音声入力・固定キー・マウスの左右入れ替え**）をする | 当日〜翌日 |
| 5 | 労災なら**請求書**を出す。私生活のけがで休むなら**傷病手当金**を確認する | 数日以内 |

## 1. 最初の10分：応急処置

### 切り傷（カッター・紙・ケースの縁など）

1. **清潔なガーゼやハンカチで傷を直接押さえる**（直接圧迫止血）。数分は離さずに押さえ続ける
2. 手を**心臓より高く**上げておく
3. 血が止まったら、**水道の流水で傷を洗い**、汚れを落とす
4. 清潔なガーゼや絆創膏で覆う

- 他人の血に触れる手当てをするときは、ビニール手袋やビニール袋越しに押さえます
- ティッシュは傷に繊維が残りやすいので、あれば清潔なガーゼかハンカチを使います

### 突き指・ドアに挟んだ・重い機材を落とした

- **冷やす**（氷のうや保冷剤をタオルで包んで当てる）、**動かさない**、**高く上げる**
- 「引っ張れば治る」は誤りです。骨折や脱臼を悪化させることがあるので、**引っ張らない**でください
- 指輪は、腫れて抜けなくなる前に外します

### 受診の目安

次のどれかに当てはまれば、その日のうちに受診します（外科・整形外科・形成外科）。

| 状態 | 理由 |
| --- | --- |
| 押さえ続けても**出血が止まらない** | 縫合が必要な可能性 |
| 傷が**深い・大きく開いている**、中に白いもの（脂肪・腱・骨）が見える | 腱や神経を傷つけている可能性 |
| 指先が**しびれる**、**曲げ伸ばしができない** | 神経・腱の損傷の可能性。放置すると機能が戻りにくい |
| **変形**している、強く**腫れて痛む** | 骨折・脱臼の可能性 |
| 爪の下が**黒紫色に腫れて**ズキズキ痛む | 爪の下の出血。処置で楽になることがある |
| ガラス片・金属片など**異物が残っている** | 自分で無理に抜かない |
| 錆びた金属・土で汚れた物で切った | 感染や破傷風の予防が必要な場合がある |

- 指が**切断**されたり、出血が**噴き出す**ように多い場合は、**119番**に通報します
- 切断された指は、**清潔なガーゼで包んでビニール袋に入れ、口を閉じて、その袋を氷水を入れた別の袋に入れて**病院へ持っていきます。指を**直接氷や水に触れさせない**でください
- 救急車を呼ぶべきか迷ったら、地域の **救急安心センター（#7119）** に相談できます（実施していない地域もあります）

## 2. 病院の受付で「どの保険か」を伝える

けがをした場面によって、使う保険が違います。**受付で最初に伝える**のが一番大事です。

| けがをした場面 | 使う保険 | 受付で伝えること |
| --- | --- | --- |
| **仕事中**（客先・自社のオフィス、出張先、作業中） | 労災保険（**業務災害**） | 「仕事中のけがです。労災でお願いします」。**保険証は出さない** |
| **通勤中**（自宅と職場の往復） | 労災保険（**通勤災害**） | 「通勤中のけがです。労災でお願いします」 |
| **私生活**（料理・スポーツ・家事） | **健康保険** | 保険証を出す |

- 仕事中・通勤中のけがに**健康保険は使えません**（健康保険法 第1条）。うっかり保険証を使ったときの切り替えは「[通勤中に転倒して病院へ。労災でやるべきこと](/articles/commute-injury-rosai)」の後半にまとめています
- **自分の不注意**（カッターの使い方を誤った、手を挟んだ）でも、仕事中であれば業務災害です。労災は「誰の責任か」を問いません
- 労災指定医療機関なら、窓口での支払いはありません

### エンジニアの「仕事中」の例

| 状況 | 業務災害？ |
| --- | --- |
| 検証機の段ボールをカッターで開けて指を切った | **なる** |
| サーバーラックのレールやケースの縁で指を切った、機材を運んでいて指を挟んだ | **なる** |
| 客先のフロアのドアやロッカーで指を挟んだ | **なる**（仕事中に職場の設備で） |
| 昼休みに社外の飲食店へ向かう途中で転んだ | 原則**ならない**（休憩中の私的な行為） |
| 昼休みでも、職場の設備（壊れた椅子など）が原因でけがをした | **なり得る**（施設の欠陥が原因の場合） |
| 在宅勤務中、業務の作業中にけがをした | **なり得る**（私的な行為中は対象外） |
| 長時間のタイピングで指・手首が痛くなった（腱鞘炎など） | 個別判断。業務との関連を労基署が判断する |

## 3. 職場への報告：けがと「作業への影響」をセットで

報告先は、**雇用主である自社**です。SES・常駐なら、**客先のリーダー**にも作業への影響を伝えます。

報告のポイントは、けがの説明だけで終わらせず、**作業がどれくらい遅れそうか、どうカバーするか**まで書くことです。読む側が一番知りたいのはそこです。

```text
件名: 業務中の負傷と、作業への影響のご報告

△△です。本日14:10頃、検証機の開梱中にカッターで左手人差し指を切りました。
□□クリニックで3針縫い、「1週間は指を使わないように」との指示です。
仕事中のけがのため、労災保険（業務災害）での手続きをお願いします。

【作業への影響】
・入力速度が通常の半分程度になる見込みです（1週間）
・レビュー指摘の修正（12件）は、明日中→明後日中に変更させてください
・テストデータ作成は、既存SQLの流用で入力量を減らして対応します
・会議・レビュー・調査系の作業は通常どおり対応できます
```

- 「打てない」ではなく「**何なら通常どおりできるか**」も書くと、作業の振り直しがしやすくなります
- 遅れの見込みは、報告が遅いほど調整が難しくなります。進捗の報告の型は「[常駐先で孤立感と不安を減らす方法](/articles/isolation-and-reporting)」も参考にしてください
- 会社に「労災は使わないで」と言われても、**請求は本人ができます**（後述）

## 4. 片手・指1本でも仕事を回す設定

けがをした日にやっておくと、翌日からの入力がかなり楽になります。

### Windows

| やりたいこと | 設定・操作 |
| --- | --- |
| 声で文字を入力したい | **音声入力**: `Win + H`。日本語も認識する。句読点は「てん」「まる」 |
| `Ctrl + C` などの同時押しを片手でしたい | **固定キー機能**: `Shift` を5回押す → 有効化。`Ctrl` を押して離してから `C` を押せば `Ctrl + C` になる |
| けがをしていない手でマウスを使いたい | **主ボタンの左右入れ替え**: 設定 → Bluetooth とデバイス → マウス → 「マウスの主ボタン」を「右」に |
| キーボードを画面上でクリックして打ちたい | **スクリーンキーボード**: `Win + Ctrl + O` |
| マウスを動かしにくい | **マウスキー**: 設定 → アクセシビリティ → マウス → マウスキー（テンキーでポインターを動かす） |

### Mac

| やりたいこと | 設定・操作 |
| --- | --- |
| 声で文字を入力したい | **音声入力**: `fn`（地球儀キー）を2回押す。システム設定 → キーボード → 音声入力 でオン |
| 同時押しを片手でしたい | **複合キー**: システム設定 → アクセシビリティ → キーボード → 「複合キー」をオン |
| 画面上のキーボードで打ちたい | **アクセシビリティキーボード**: システム設定 → アクセシビリティ → キーボード |

### 入力の「量」そのものを減らす

| 方法 | 例 |
| --- | --- |
| **IMEの単語登録** | 「よろ」→「よろしくお願いいたします。」、「ほう」→ 報告メールの定型文 |
| **エディタのスニペット** | VS Code のユーザースニペットで、よく書く関数の雛形・SQLの定型を登録する |
| **コード補完・生成AI** | 補完の候補を Tab で確定するだけで入力量が大きく減る。社内ルールで使ってよい範囲を確認する |
| **既存資産の流用** | テストデータは既存のSQLやExcelから作る（「[UT用のテストデータ作成を時短する5つの方法](/articles/ut-test-data-without-dummy-program)」） |
| **会議・レビュー中心に入れ替える** | 打鍵の多い実装を他の人に、レビュー・調査・設計の確認を自分に、と振り替えを相談する |

- 包帯やテーピングの指は、**浮かせたまま**打つ癖をつけると、傷に負担がかかりません
- 傷口が開いていたり、濡れた包帯のままの場合は、キーボードを触る前に**乾いた清潔なもの**に替えます。共用のキーボードは、治るまで自分専用の物を借りるのも手です
- 痛みを我慢して打ち続けると、治りが遅くなります。**医師の「使わないように」の指示が最優先**です

## 5. お金の話：労災・健康保険それぞれでもらえるもの

### 仕事中のけが（業務災害）

| 給付 | 様式 | 内容 |
| --- | --- | --- |
| 治療費 | **様式第5号**（労災指定病院に提出） | 窓口負担なし。指定外で全額払った場合は**様式第7号**で労基署に請求 |
| 休業 | **様式第8号** | 4日目から、給付基礎日額の**60%＋特別支給金20%** |
| 最初の3日間 | （会社が支払う） | 業務災害は、会社が平均賃金の**60%以上**を補償する義務がある（労働基準法 第76条） |
| 後遺障害が残った | 様式第10号 | 指の欠損や曲がりにくさが残った場合、障害等級に応じて**障害（補償）給付**の対象になり得る |

- 様式第5号・第8号には**事業主の証明欄**があります。会社に証明をもらって提出します。会社が証明してくれない場合は、その事情を書いて**労働基準監督署に相談**すれば、本人が請求できます
- 休業4日以上なら、会社は**労働者死傷病報告**を労基署に出す義務があります（4日未満は四半期ごと。2025年1月から原則**電子申請**）
- 業務災害の療養のために休業している期間とその後30日間は、**解雇が制限**されます（労働基準法 第19条）

### 通勤中のけが（通勤災害）

様式は**第16号の3**（治療費）・**第16号の6**（休業）です。最初の3日間の会社の補償義務がないなど、業務災害との違いは「[通勤中に転倒して病院へ。労災でやるべきこと](/articles/commute-injury-rosai)」に詳しく書いています。

### 私生活のけが（健康保険）

会社員として健康保険（協会けんぽ・健保組合）に入っていれば、けがで仕事を休んだときに**傷病手当金**があります（健康保険法 第99条）。

| 項目 | 内容 |
| --- | --- |
| 条件 | 仕事に就けない状態で、**連続する3日間**（待期）を含めて休み、4日目以降も休んだ |
| 金額 | 1日あたり、おおむね**標準報酬日額の3分の2** |
| 期間 | 支給開始から通算**1年6か月** |
| 注意 | 有給休暇で給与が出た日は支給されない。**国民健康保険には原則この制度がない** |

### 個人事業主・フリーランスの場合

雇われていない個人事業主は、原則として**労災保険の対象外**です。ただし、**特別加入**していれば補償を受けられます。2024年11月から、企業から業務委託を受けるフリーランスも特別加入できるようになっています。加入していない場合は、国民健康保険で受診することになります。

## よくある質問

| 質問 | 答え |
| --- | --- |
| 小さな切り傷でも労災にする？ | 病院にかかるなら、**労災で受診**します。後で化膿したり、腱を傷めていたと分かったときに、記録がないと説明が難しくなる |
| 自分の不注意でも労災？ | 仕事中であれば**労災**。労災保険は過失の有無を問わない（重大な過失の場合に給付が制限されることはある） |
| 労災を使うと会社に迷惑では？ | 会社が手続きをする義務があり、**労災を使わせない「労災隠し」は違法**（労働安全衛生法 第100条違反などになり得る） |
| 客先でけがをした。客先の労災？ | SES・派遣を問わず、労災の手続きは**雇用主（自社）**。派遣の場合は派遣元の労災を使う |
| 会社がテレワークを認めてくれない | けがだけを理由に会社が認める義務はないが、医師の意見書（「通勤の負担を避けるのが望ましい」など）を添えて**就業上の配慮**として相談するのが現実的 |
| 治療中にまたけがをした | 「[労災の治療中に2回目の労災。どうする？](/articles/second-rosai-during-treatment)」を参照 |

## チェックリスト

- [ ] 直接圧迫で止血し、流水で洗った（突き指は冷やして引っ張らない）
- [ ] 受診の目安（止まらない・深い・しびれ・変形・異物）を確認し、当てはまれば受診した
- [ ] 仕事中・通勤中なら、受付で「労災で」と伝え、保険証を出さなかった
- [ ] 自社（と客先）に、けがの状況と**作業への影響・対策**をセットで報告した
- [ ] 音声入力・固定キー・マウスの左右入れ替え・スニペットを設定した
- [ ] 打鍵の多い作業の振り直しを相談した
- [ ] 労災なら様式第5号（通勤は第16号の3）を病院へ。休むなら第8号（通勤は第16号の6）
- [ ] 私生活のけがで3日以上休むなら、傷病手当金の対象か確認した

## まとめ

- 応急処置は**直接圧迫・高く上げる・流水で洗う**。突き指は**冷やして引っ張らない**
- **止まらない・深い・しびれる・動かない・変形**は受診。切断や大量出血は**119番**、迷ったら **#7119**
- **仕事中のけがは自分の不注意でも労災**。受付で「労災で」と伝え、保険証は出さない
- 報告は「けが」と「**作業への影響・カバー方法**」をセットで、当日中に
- **音声入力（Win+H / fn 2回）、固定キー、スニペット、生成AI補完**で、指1本でも仕事は回せる。ただし医師の指示が最優先
