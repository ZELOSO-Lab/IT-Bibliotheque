# 【労務】準委任（SES）で残業が月100時間を超えたら何が起きる？ 契約解除・産業医面談・過労死ライン・休職の「本当のところ」

> **最終確認日: 2026年10月23日**（労働基準法・労働安全衛生法・同規則・民法、e-Gov法令検索と厚生労働省の公表資料で確認）。一般的な決まりの解説です。自分のケースは、雇用契約書・就業規則を確認したうえで、労働基準監督署・総合労働相談コーナーなどの窓口に相談してください。

## 現場の声

リリース前の月、残業が100時間に届きそうになった頃、同じ常駐先の先輩からこう言われました。

「準委任で100時間超えたら、契約解除だよ。産業医面談に呼ばれて、過労死ラインって判定されて、そのまま休職になる」

怖くなって調べると、半分は正しく、半分は誤解でした。

- **過労死ライン**や**法律の上限**は、法律や国の基準で決まっている
- **契約解除**や**休職**は、法律で自動的に決まるものではなく、**会社同士の契約や社内規程の運用**で決まる
- **産業医面談**は「月80時間超＋本人の申出」が法律上の基準で、100時間で自動的に始まるわけではない

この記事は「[36協定を結んでいたら何時間まで働ける？](/articles/saburoku-kyotei-overtime-limit)」の続編です。上限の数字そのものはそちらで整理しているので、ここでは「**超えたら実際に何が起きるのか**」を切り分けます。

## 結論：100時間で「自動的に」起きることはない

| 聞いた話 | 本当のところ | 決めているもの |
| --- | --- | --- |
| 100時間超は違法 | **正しい**。時間外＋休日労働は**月100時間未満**が上限。100時間ちょうどでも違反。違反の責任を負うのは**雇用主（自社）** | 労働基準法 第36条第6項 |
| 過労死ラインを超える | **正しい**。発症前1か月におおむね100時間超、または2〜6か月平均で月80時間超の時間外労働は、業務と脳・心臓疾患の関連が強いと評価される | 厚生労働省の労災認定基準 |
| 産業医面談になる | **条件付き**。法律上の基準は「**月80時間超＋疲労の蓄積＋本人の申出**」。100時間で自動実施ではない | 労働安全衛生法 第66条の8 |
| 契約解除になる | **法律ではない**。会社同士の契約や運用次第。ただし、客先が要員交代を求めることは実際にある | 会社間の契約、民法 第651条 |
| 休職になる | **自動ではない**。医師が休業が必要と判断した場合などに、就業規則に沿って決まる | 就業規則、医師の意見 |

もう1つ、準委任ならではの注意点があります。**客先が直接「残業して」と指示すること自体が、偽装請負になるおそれがあります**（後述）。

## 前提：準委任では「誰の残業」なのか

SES（準委任契約）で客先に常駐していても、あなたを雇っているのは**自社**です。

| 立場 | 労働時間について負う責任 |
| --- | --- |
| 自社（SES会社・雇用主） | 36協定、労働時間の把握、残業代、医師の面接指導、安全配慮義務。**ほぼすべて自社** |
| 客先（発注者） | 雇用主ではない。**作業の指示や残業の指示をしてはいけない**立場 |

- 残業の上限は**自社の36協定**で決まります。客先の36協定ではありません
- 会社には、労働者の**労働時間の状況を把握する義務**があります（労働安全衛生法 第66条の8の3）。常駐先にいても同じです
- 会社は、労働者が安全に働けるよう配慮する義務（**安全配慮義務**）も負います（労働契約法 第5条）

## 1. 「100時間超は違法」：正しい

36協定に特別条項があっても、**時間外労働＋休日労働は月100時間未満**でなければなりません（労働基準法 第36条第6項第2号）。さらに、**2〜6か月のどの平均も80時間以内**です（同第3号）。

- 「未満」なので、**100時間ちょうどでも違反**です
- **休日労働も含めて**数えます
- 違反した場合に罰則の対象になるのは、雇用主である**自社**です（6か月以下の拘禁刑または30万円以下の罰金、第119条）

数え方と例外は「[36協定を結んでいたら何時間まで働ける？](/articles/saburoku-kyotei-overtime-limit)」で詳しく解説しています。

## 2. 「過労死ラインを超える」：正しい

「過労死ライン」は法律の用語ではなく、**厚生労働省の労災認定基準**で使われる時間の目安を指す通称です。

### 脳・心臓疾患（令和3年9月改正の認定基準）

| 時間外労働 | 評価 |
| --- | --- |
| 発症前1か月におおむね**100時間超** | 業務と発症の関連性が**強い** |
| 発症前2〜6か月のいずれかの平均で月おおむね**80時間超** | 業務と発症の関連性が**強い** |
| 上の水準に近い時間外労働＋**労働時間以外の負荷**（不規則な勤務、休日のない連続勤務、精神的な緊張など） | 総合的に評価し、関連性が強いと判断されることがある |

### 精神障害（令和5年9月改正の認定基準）

| 時間外労働 | 心理的負荷の評価 |
| --- | --- |
| 発病直前1か月におおむね**160時間超**（3週間におおむね120時間以上など） | 「特別な出来事」（極度の長時間労働） |
| 発病直前の連続2か月間に月おおむね**120時間以上** | 「強」 |
| 発病直前の連続3か月間に月おおむね**100時間以上** | 「強」 |
| 月おおむね100時間の**恒常的長時間労働**＋仕事上の出来事 | 出来事の心理的負荷を「強」に修正することがある |

- ここでの「時間外労働」は、**週40時間を超えて働いた時間**です
- 「判定」と聞くと会社が判定するように聞こえますが、実際に判断するのは、**病気になって労災を請求したときの労働基準監督署**です。100時間を超えた時点で誰かが「過労死ライン」と判定する手続きがあるわけではありません
- 基準に届かなくても、ほかの負荷とあわせて労災と認められることがあります

## 3. 「産業医面談になる」：条件付き

法律で決まっているのは「**医師による面接指導**」です（労働安全衛生法 第66条の8）。流れは次のとおりです。

```text
1. 会社が毎月、時間外＋休日労働を算定する
2. 80時間を超えた人には、会社が本人に時間を通知する（安衛則 第52条の2第3項）
   同時に、会社が産業医に氏名と時間を伝える（安衛則 第14条の2）
3. 本人が「面接指導を受けたい」と申し出る（申出の要件: 80時間超＋疲労の蓄積）
4. 会社は遅滞なく、医師の面接指導を行う（安衛則 第52条の3）
5. 会社は医師の意見を聴き、必要なら残業の削減・作業の転換・就業場所の変更などを行う（法 第66条の8第4項・第5項）
```

| 対象 | 面接指導の扱い |
| --- | --- |
| 一般の労働者 | 月80時間超＋疲労の蓄積＋**本人の申出**で、会社に実施義務 |
| 研究開発業務の従事者 | 月**100時間超**なら、申出がなくても実施義務（法 第66条の8の2） |
| 高度プロフェッショナル制度の適用者 | 健康管理時間が基準を超えたら、申出がなくても実施義務（法 第66条の8の4） |

- 一般のシステム開発・保守の仕事なら、100時間を超えても**自分から申し出ないと始まらない**のが法律上の形です。100時間超で面談を必須にしている会社は多いですが、それは**社内規程の運用**です
- 産業医は、対象者に申出を勧めることができます
- 申し出たことを理由に、不利益な扱いをしてはいけないとされています
- 産業医がいない小規模な会社（常時50人未満）でも、面接指導の義務はあります。地域産業保健センターなどを使って実施します

**「面談に行ったら評価が下がりそう」と思って申し出ない人が多いのですが、面接指導は自分を守るための制度です。** 80時間を超えたら、ためらわず申し出てください。

## 4. 「契約解除になる」：法律ではない

### 法律で決まっていること

- 準委任契約（会社同士）は、民法上**いつでも解除できます**。ただし、相手に不利な時期に解除した場合などは損害賠償の対象になります（民法 第651条、第656条）
- 実務では、契約期間（1〜3か月単位が多い）と、更新しない場合の通知期限を決めて運用するのが一般的です
- 「月100時間を超えたら契約を解除する」と定めた法律はありません

### 実際に起きやすいこと（運用の傾向）

| よくある動き | 理由 |
| --- | --- |
| 自社の営業が、客先に**稼働を抑えるよう申し入れる** | 違反の責任を負うのは自社。客先に作業量の調整を頼むしかない |
| 客先が**要員の交代**や**増員**を求める | 客先も、取引先の法令違反に関わるとコンプライアンス上の問題になる |
| 契約の**精算幅**（例: 月140〜180時間）を超えた分の扱いで揉める | 精算幅は請求の取り決めで、残業の上限ではない |
| 次の更新を見送られる | 稼働の多さより「計画どおり進まない」ことが理由になることが多い |

- ここで終わるのは**会社同士の契約**です。正社員なら、自社との**雇用契約は続きます**
- 「長時間働いたから解雇」は、客観的に合理的な理由とは言えません（労働契約法 第16条）
- 案件が終わった後の待機や給与については「[契約を切られるのが怖い時の備え](/articles/contract-end-anxiety)」で解説しています

## 5. 「休職になる」：自動ではない

**休職は法律で決まった制度ではありません**。多くの会社が就業規則で定めている制度で、条件・期間・給与の扱いは会社ごとに違います。

| きっかけ | どうなるか |
| --- | --- |
| 面接指導で、医師が「就業制限」や「休業」が必要と意見を出した | 会社が医師の意見を勘案して、残業禁止・業務の軽減・休業などの措置を決める |
| 主治医が「休養が必要」と診断書を出した | 本人の申出と就業規則に沿って、休職などが決まる |
| 100時間を超えただけ | **それだけで休職にはならない** |

休むことになった場合のお金の目安です。

| 原因 | 主な給付 | 目安 |
| --- | --- | --- |
| 業務が原因（労災と認定された場合） | 労災保険の**休業（補償）給付** | 休業4日目から、給付基礎日額の60%＋休業特別支給金20% |
| 業務外の病気・けが | 健康保険の**傷病手当金** | 休業4日目から、標準報酬日額の3分の2（支給開始から通算1年6か月まで） |

- 業務上の病気で休業している期間とその後30日間は、原則として**解雇できません**（労働基準法 第19条）
- 体調の判断は自分でせず、**医師に相談**してください。限界のサインと受診の目安は「[高稼働で追い込まれた時に最初にやること](/articles/overwhelmed-first-aid)」にまとめています

## 6. 準委任ならではの落とし穴：客先の「残業して」は偽装請負のおそれ

準委任（業務委託）契約では、**客先とあなたの間に指揮命令関係があってはいけません**。客先が直接、細かな作業の指示や、出退勤・勤務時間の管理をしていると、実態は労働者派遣とみなされ、「**偽装請負**」として違法になるおそれがあります（厚生労働省・東京労働局の解説では、準委任も対象と明記）。

| 客先の言動 | 問題になりやすい理由 |
| --- | --- |
| 「今日は22時まで残って」と本人に直接言う | 勤務時間の指示＝指揮命令 |
| 「土曜も来て」と本人に直接言う | 休日労働の指示＝指揮命令 |
| 客先のリーダーが、作業の順番や担当を本人に直接割り振る | 業務の細かな指示＝指揮命令 |
| 自社の責任者は、客先の指示をそのまま伝えるだけ | 「形式だけ責任者型」の偽装請負 |

本人ができる対応は次の3つです。

1. **「自社の責任者（営業）を通して依頼してください」と伝える**。角が立つ場合は「勤務時間は自社の管理なので、確認します」で十分です
2. **言われた日時と内容を記録する**（メモ・チャットの履歴）
3. **自社の営業・責任者に、稼働時間の実績とあわせて報告する**

報告の型は「[常駐先で会話に入れない時の「事実の記録」と「報告の型」](/articles/isolation-and-reporting)」が使えます。

## 100時間が見えてきた時にやること

| タイミング | やること |
| --- | --- |
| 月45時間を超えそう | 自社の36協定の特別条項の手続きが取られているか、自社に確認する |
| 月80時間を超えそう | 直近2〜6か月の**平均**を計算する。疲れが溜まっていたら**面接指導を申し出る** |
| 月100時間に近づいた | **自社の営業に、数字で報告**する（今月の実績と、月末までの見込み）。客先に直接交渉しない |
| 客先から直接残業を指示された | 自社を通すよう伝え、記録して自社に報告する |
| 体調が悪い（眠れない・食べられない・涙が出る） | 時間に関係なく**医師に相談**する |

自社の営業への報告は、次のような短い文で十分です。

```text
件名: 今月の稼働時間の見込みについて

○○案件の△△です。今月の時間外労働が、本日時点で72時間です。
現在の作業量だと、月末までに100時間前後になる見込みです。
36協定の上限を超えるおそれがあるため、客先との作業量の調整をご相談させてください。
（実績: 勤怠システムの記録のとおり。客先からの依頼内容は別途まとめています）
```

## まとめ

- **月100時間以上（休日労働込み）は、雇用主である自社の労基法違反**。過労死ライン（1か月100時間超・2〜6か月平均80時間超）も国の基準として正しい
- **産業医面談（医師の面接指導）は「月80時間超＋申出」が法律上の基準**。100時間で自動的に始まるのは社内規程の運用
- **契約解除・休職は、法律で自動的に決まるものではない**。会社同士の契約や就業規則、医師の判断で決まる
- 準委任では、**客先が直接残業を指示すること自体が偽装請負のおそれ**。指示は自社を通す
- 100時間が見えたら、**数字を添えて自社の営業に早めに報告**する

困ったときは、厚生労働省の「労働条件相談ほっとライン」、最寄りの労働基準監督署・総合労働相談コーナーに相談できます。心身の不調は「こころの耳」の電話・メール・SNS相談も使えます。
