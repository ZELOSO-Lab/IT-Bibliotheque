# 【サクラエディタ】「100行の先頭に同じ文字を足す」を一瞬で終わらせた話と、置換の正規表現・矩形選択の使い方

## 現場の声

> DB設計書の列一覧を Excel からコピーして、C言語の構造体や SQL の形に整える作業がありました。最初は1行ずつ先頭に空白を入れ、行末にセミコロンを打っていましたが、数十行あると時間もかかり、打ち漏れも出ます。
>
> サクラエディタの置換で、**「行頭」を表す `^`** と **「行末」を表す `$`** を使えば、全行の先頭や末尾に同じ文字を一度で付けられると知りました。さらに、**矩形選択（範囲選択）**で縦に選べば、表の1列だけを切り取ったり貼り付けたりできます。
>
> どちらも「知っていれば一瞬、知らなければ手作業」の機能でした。

サクラエディタは、Windows の現場で今も多く使われている国産のテキストエディタです。この記事では、ソースや SQL、ログの体裁を整えるときに役立つ機能を、場面ごとに紹介します。

## 前提の構成

| 項目 | 内容 |
| --- | --- |
| エディタ | サクラエディタ 2.4 系（Windows） |
| キー割り当て | 既定 |
| 主な用途 | ソース・SQL・ログ・Excel から貼り付けたデータの整形 |

ショートカットは設定によって変わることがあります。「設定 → 共通設定 → キー割り当て」で確認・変更できます。

**正規表現を使う準備**

置換ダイアログの「正規表現」にチェックが入れられない場合は、正規表現ライブラリ（`bregonig.dll`）が必要です。最近のインストーラには同梱されていますが、古い環境では別途入れる必要があります。

## 場面1：全行の先頭に同じ文字を付けたい（`^`）

**使う機能**：置換（**Ctrl+R**）＋ 正規表現の `^`

`^` は「行の先頭」を表します。文字ではなく**位置**なので、`^` を置換すると「先頭に文字を挿入する」ことになります。

| 置換前 | 置換後 | 結果 |
| --- | --- | --- |
| `^` | `-- ` | 全行をSQLのコメントにする |
| `^` | `    ` | 全行の先頭に半角スペース4つ（インデント） |
| `^` | `// ` | 全行をC言語のコメントにする |

**手順**

1. 対象の行を選択する（選択しなければファイル全体）
2. **Ctrl+R** で置換ダイアログを開く
3. 「**正規表現**」にチェック
4. 置換前に `^`、置換後に付けたい文字を入力
5. 選択範囲だけなら「範囲」を「選択範囲」にして「**すべて置換**」

```text
emp_no         →  -- emp_no
emp_name       →  -- emp_name
dept_cd        →  -- dept_cd
```

## 場面2：全行の末尾に同じ文字を付けたい（`$`）

**使う機能**：置換 ＋ 正規表現の `$`

`$` は「行の末尾」を表します。

| 置換前 | 置換後 | 結果 |
| --- | --- | --- |
| `$` | `,` | SELECT 句の列名にカンマを付ける |
| `$` | `;` | C言語の文の末尾にセミコロンを付ける |
| `^(.*)$` | `'$1',` | 全行を `'...'` で囲み、カンマを付ける（IN 句用） |

3つ目の `(.*)` は「行全体」を、置換後の `$1` は「カッコで囲んだ部分」を表します。Excel から貼り付けたコードの一覧を、そのまま SQL の `IN (...)` の中身にできます。

```text
A001     →  'A001',
A002     →  'A002',
A003     →  'A003',
```

最終行のカンマだけ手で消せば完成です。

## 場面3：Excel から貼り付けたデータを、タブ区切りのまま整形したい（`\t`）

**使う機能**：置換 ＋ `\t`（タブ）＋ `( )` と `$1` `$2`

Excel のセルをコピーして貼り付けると、**列と列の間はタブ**になります。`\t` でタブを指定できるので、「列ごとに取り出して並べ替える」ことができます。

| 置換前 | 置換後 | 結果 |
| --- | --- | --- |
| `\t` | `,` | タブ区切りをカンマ区切り（CSV）にする |
| `^(\w+)\t(\w+)$` | `$2 = $1` | 1列目と2列目を入れ替えて `=` でつなぐ |
| `^(\w+)\tvarchar2\t(\d+)$` | `    char $1[$2 + 1];` | 列定義を C の構造体メンバにする |

最後の例は、DB設計書から C言語の構造体を作り直したときに使いました（「Pro*C の構造体 INTO」の記事で詳しく紹介しています）。

## 場面4：表の1列だけを選択・コピー・削除したい（矩形選択）

**使う機能**：矩形選択（**Alt を押しながらドラッグ**、または **Shift+Alt+矢印キー**）

通常の選択は「行」単位で流れるように選ばれますが、矩形選択では**四角い範囲**を選べます。

```text
emp_no     VARCHAR2  10
emp_name   VARCHAR2  40
dept_cd    CHAR      4
           ^^^^^^^^^
           この列だけを縦に選べる
```

**できること**

| 操作 | 結果 |
| --- | --- |
| 矩形選択して **Delete** | 1列だけを削除する |
| 矩形選択して **Ctrl+C** → 別の場所で **Ctrl+V** | 1列だけを、別の場所に「縦のまま」貼り付ける |
| 矩形選択して **Ctrl+U** / **Ctrl+Shift+U** | その範囲だけ小文字 / 大文字にする |

キーボードで始めたいときは、**Shift+F6**（矩形範囲選択開始）を押してからカーソルを動かす方法もあります。

**ポイント**

- 縦がそろっていないと矩形選択はうまくいきません。タブとスペースが混ざっているときは、先に「**変換 → TAB→空白**」でそろえます
- ログの「時刻の列だけ消したい」「先頭の行番号だけ消したい」ときにも便利です

## 場面5：大文字・小文字をまとめて変えたい

**使う機能**：「変換」メニュー

| 操作 | 既定のショートカット |
| --- | --- |
| 英大文字 → 英小文字 | **Ctrl+U** |
| 英小文字 → 英大文字 | **Ctrl+Shift+U** |
| 全角 → 半角、半角 → 全角 | 「変換」メニューから |
| TAB → 空白、空白 → TAB | 「変換」メニューから |

DB設計書の列名（大文字）を C のメンバ名（小文字）にするときは、全選択して Ctrl+U で一度に変換できます。

## 場面6：複数のファイルから文字列を探したい（Grep）

**使う機能**：Grep（**Ctrl+G**）

フォルダを指定して、配下のファイルから文字列を検索します。結果の行をダブルクリックすると、そのファイルの該当行が開きます。

| 設定 | 例 |
| --- | --- |
| 条件 | `EMP_REC` |
| ファイル | `*.c;*.h;*.pc` |
| フォルダ | `C:\work\src` |
| オプション | 「サブフォルダからも検索」にチェック |

構造体を変更したときに、**その構造体を使っているソースをすべて洗い出す**のに使います。サクラエディタのバージョンによっては、Grep の画面から複数ファイルの一括置換（Grep置換）もできます。

## 場面7：並べ替え・重複の削除をしたい

**使う機能**：「編集 → 高度な操作」

| 操作 | 内容 |
| --- | --- |
| 選択行の昇順ソート / 降順ソート | 選択した行を並べ替える |
| 連続した重複行の削除（uniq） | 連続した重複行を1行にする（バージョンにより名称が異なります） |

並べ替えてから重複を削除すると、コード一覧などの重複をまとめて取り除けます。

## よく使う正規表現の早見表

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `^` | 行頭 | `^` → `-- `（全行をコメントに） |
| `$` | 行末 | `$` → `,`（全行の末尾にカンマ） |
| `.` | 任意の1文字 | `a.c` は abc、a1c に一致 |
| `.*` | 任意の文字の繰り返し | `^.*ERROR.*$`（ERROR を含む行全体） |
| `\t` | タブ | `\t` → `,`（タブ区切り → CSV） |
| `\d` / `\w` | 数字 / 英数字と `_` | `\d+`（1桁以上の数字） |
| `\s` | 空白 | `\s+$` → 空（行末の空白を削除） |
| `( )` と `$1` | 一致した部分を置換後で使う | `^(.*)$` → `'$1',` |
| `^\r?\n` | 空行 | 空に置換すると空行を削除 |

## チェックリスト

- [ ] 置換ダイアログで「正規表現」にチェックできる（できなければ `bregonig.dll`）
- [ ] 行頭は `^`、行末は `$` で文字を付けられる
- [ ] Excel から貼り付けたデータはタブ区切り（`\t`）だと知っている
- [ ] `( )` で囲んだ部分を `$1` で置換後に使える
- [ ] Alt+ドラッグ / Shift+Alt+矢印キーで矩形選択できる
- [ ] 矩形選択の前に TAB と空白をそろえている
- [ ] 範囲を選んでから「すべて置換」すると、選択範囲だけを置換できる
- [ ] 置換前に元のファイルを保存し、失敗したら Ctrl+Z で戻せる

## まとめ

- サクラエディタの置換で、**行頭の `^`** と **行末の `$`** を使うと、全行の先頭・末尾に同じ文字を一度で付けられます。
- `\t` と `( )` / `$1` を組み合わせると、Excel から貼り付けた表を、構造体・SQL・CSV などの形にまとめて変換できます。
- **矩形選択**（Alt+ドラッグ）を使うと、表の1列だけを削除・コピー・変換できます。

「1行ずつ手で直す」作業が出てきたら、まず置換と矩形選択で一度にできないかを考えてみてください。
