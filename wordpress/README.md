# WordPress 技術まとめページ 作成手順

ポータル（React 版）の各技術ページにある「技術まとめはこちら」と「項目から探す」のリンク先として、
WordPress.com（https://itbibliotheque.wordpress.com/）に技術ごとの固定ページを作ります。

## ファイル

| ファイル            | 内容                                                              |
| ------------------- | ----------------------------------------------------------------- |
| `pages.csv`         | 作成する33ページの一覧（タイトル・スラッグ・URL）。進捗チェック用 |
| `pages/{slug}.html` | 各ページの本文の雛形（ブロックエディタ形式）                      |

雛形には、目次、7つの見出し（基礎・環境構築・コマンド・サンプル・エラー対応・実務Tips・関連リンク）、
主な用途、クイックリファレンス、公式ドキュメントへのリンクがあらかじめ入っています。
「（執筆予定）」の部分を書き換えれば完成です。

## 1ページの作り方（約3分）

1. WordPress 管理画面 → 固定ページ → 新規追加
2. タイトルに `pages.csv` の「ページタイトル」を入力（例: `Java 技術まとめ`）
3. 右上の「︙」→「コードエディター」に切り替え
4. `pages/{slug}.html` の中身をすべて貼り付け →「コードエディターを終了」
5. 右サイドバー「ページ」→「URL（パーマリンク）」のスラッグを `pages.csv` の値にする（例: `java`）
6. 公開

> スラッグが違うとポータルからのリンクが切れます。必ず `pages.csv` と同じ値にしてください。

## 見出しのアンカーについて

各見出しには `basics` / `setup` / `commands` / `samples` / `errors` / `tips` / `links` のアンカーが設定済みです
（見出しブロック →「高度な設定」→「HTML アンカー」）。ポータルの「項目から探す」はこのアンカーに直接移動するため、
見出しを作り直す場合も同じアンカー名を付けてください。

## URL を変える場合

- すべて変える: ポータルの `src/config/site.ts` の `summaryBaseUrl`
- 1技術だけ変える: `src/data/technologies.ts` の該当技術に `url` を指定
- 変更後は `npm run wp:generate` で雛形と `pages.csv` を再生成できます
