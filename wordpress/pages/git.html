コマンド

基本の流れ

git status
git add .
git commit -m "メッセージ"
git push origin main

ブランチ作成と切り替え

git switch -c feature/login
git switch main

直前のコミットを修正

git commit --amend

作業中の変更を退避

git stash
git stash pop
