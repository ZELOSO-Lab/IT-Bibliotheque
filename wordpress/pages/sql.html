コマンド

JOIN

SELECT o.id, c.name
FROM orders o
INNER JOIN customers c ON c.id = o.customer_id;

グループ集計

SELECT category, COUNT(*), SUM(amount)
FROM sales
GROUP BY category
HAVING SUM(amount) > 10000;

更新前に件数確認
